## Where savingplanets.com Is Ahead
- Positive-action, sourced solutions catalog (305 across 11 hubs) with consistent Five W’s structure.
- Interactive World Map with pins.
- 6-language coverage including RTL.
- Teacher Sheets with NGSS/Common Core tags + grade filters.
- TES integration + OER Commons listing.
- Aerospace / jet-propulsion self-study undergraduate path (modeled on Embry-Riddle catalog, clearly labeled non-accredited).
- Sister site beforesavingplanets.com.
- Static, fast, accessible site with Lesson Builder and Match tools.

## Top Gaps (Priority Order)
1. **High – Teacher workflow tools**  
   Missing class management, assignment tracking, student progress, full Google Classroom bidirectional sync. PBS and Khan set the bar.

2. **High – Interactive practice & mastery**  
   No adaptive practice, quizzes with instant feedback, or AI tutor. Khan Academy leads here.

3. **Medium – Video / lecture depth**  
   Yale/MIT/PBS offer full recorded lectures. SP is text + sheets. Add short solution videos or embed partner lectures.

4. **Medium – Broader standards & filters**  
   Expand beyond NGSS/CCSS to state standards (PBS model) and more granular subject filters.

5. **Medium – University / OER pathway**  
   Strengthen Undergraduate_Studies with more live courses, clearer sequencing, and additional degree-path models. Increase OER Commons / TES volume.

6. **Low – Scale of content**  
   305 solutions vs MIT’s 2500+ courses. Focus on quality depth over raw count.

## Actionable Recommendations (Priority)
1. **P1 – Classroom & progress tools**  
   Add Google Classroom assignment export + optional class roster view. Simple progress checklist per solution sheet.

2. **P1 – Interactive layer**  
   Lightweight quizzes or “Match” expansions on Teacher Sheets. Link to external practice (Khan, CK-12) where relevant.

3. **P2 – Video shorts**  
   30–60s solution explainers (already doing some on YouTube). Embed on solution pages.

4. **P2 – Standards expansion**  
   Add state-standard tags for top 5–10 states. Filter UI already exists—extend data.

5. **P2 – Aerospace path completion**  
   Finish planned Year 3–4 cards. Add technical writing / general-education gap note as optional modules.

6. **P3 – Discovery**  
   Improve semantic search prominence. Add “related by NGSS code” suggestions.
