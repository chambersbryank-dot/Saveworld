## Where savingplanets.com is Ahead
- Positive-action framing + verifiable impact numbers (no doom).
- Multi-language (6) with RTL support and hreflang.
- World Map pins + solution hubs tied to real projects.
- Teacher Sheets with specific NGSS/CCSS codes + Classroom/IMSCC exports.
- Aerospace/jet propulsion track + sister site integration.
- TES integration + Lesson Builder + Match.
- PWA, static speed, privacy-focused search (MIT open-source).

## Top Gaps (Priority)
1. **High:** Adaptive practice / mastery tracking (Khan/CK-12 style) — add skill trees or quizzes per solution/course.
2. **High:** Broader standards alignment + filters (beyond NGSS/CCSS; add state, IB, or international).
3. **Medium:** More interactive media / simulations (PBS/NASA/CK-12) — expand Lesson Builder or add simple interactives.
4. **Medium:** Live or recorded expert sessions (Nat Geo Explorer Classroom model).
5. **Medium:** Full course depth parity (more problem sets, exams, transcripts) on existing aerospace track.
6. **Low:** Additional languages or auto-translation quality review.
7. **Low:** OER Commons / TES deeper syndication.

## Actionable Recommendations (Priority)
- **P1 (this quarter):** Build simple quiz/skill layer on top solutions and courses. Export to Classroom. Tag more standards.
- **P1:** Expand Teacher Sheets filters (grade band already there; add subject deep-links and download packs).
- **P2:** Partner for short expert videos or live classroom slots (space/aerospace first).
- **P2:** Add 2-3 interactive map or simulation modules (ocean cleanup, orbital).
- **P3:** Native review of AR/HE translations; expand to 1-2 more languages if demand.
- **P3:** Formal OER Commons listing + improved TES collections.
