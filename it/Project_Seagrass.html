Project Seagrass

Project Seagrass, un ente benefico britannico, ha piantato oltre 150.000 semi di fanerogame marine per far rinascere le praterie sottomarine (dati dell’organizzazione).

Immagine: NASA/KSC (KSC-20230329-PH-KLS01_0304, progetto di ripristino delle praterie marine).

Le cinque W di Project Seagrass

Chi

Progetto Seagrass, una carità registrata in Inghilterra e Galles (1162824) e Scozia (SC046788).

Fonte: Project Seagrass

Cosa

Proteggere e ripristinare le praterie marine con il lavoro delle comunità, la ricerca e la semina.

Fonte: Project Seagrass

Quando

Lavorando dal 2013; riporta più di 150.000 semi piantati e 3.000+ nuovi punti dati di seagrass.

Fonte: Project Seagrass

Dove

Con sede a Bridgend, Galles, Regno Unito, lavorando dalle sponde locali alla politica internazionale.

Fonte: Project Seagrass

Perché

Molti prati di erba marina stanno cambiando di circa 1–2% all'anno, e piccole perdite aggiungono fino a grandi riduzioni.

Fonte: Project Seagrass

Dichiarazione d'impatto

Soluzione non profit · attiva

Il progetto Seagrass riferisce più di 150.000 semi di erba marina piantati e più di 3.000 nuovi punti di dati di seagrass (dati dell’organizzazione).

Fonte: Project Seagrass

Per saperne di più: Project Seagrass

Seagrass non è alghe: è una pianta fiorita che forma prati sott'acqua.

Come aiuta le persone e il pianeta

Per le persone

I prati di Seagrass sostengono la pesca, stabilizzano le coste e migliorano la qualità dell'acqua per le comunità costiere.

Fonte: Project Seagrass

Per la natura

I prati riparano la vita marina e immagazzinano il carbonio, così il ripristino li aiuta il mare e il clima.

Fonte: Project Seagrass
