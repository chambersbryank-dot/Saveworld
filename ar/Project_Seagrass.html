Project Seagrass

زرعت Project Seagrass، وهي جمعية خيرية بريطانية، أكثر من 150,000 بذرة لإعادة المروج تحت الماء (أرقام المنظمة).

الأسئلة الخمسة عن Project Seagrass

مَن

Project Seagrass، جمعية خيرية مسجلة في إنجلترا وويلز (1162824) واسكتلندا (SC046788).

المصدر: Project Seagrass

ماذا

حماية مروج الأعشاب البحرية واستعادتها عبر العمل المجتمعي والبحث والزراعة.

المصدر: Project Seagrass

متى

تعمل منذ عام 2013؛ وتفيد بزراعة أكثر من 150,000 بذرة وجمع أكثر من 3,000 نقطة بيانات جديدة عن الأعشاب البحرية.

المصدر: Project Seagrass

أين

مقرها في بريدجند، ويلز، المملكة المتحدة، وتعمل من الشواطئ المحلية حتى السياسات الدولية.

المصدر: Project Seagrass

لماذا

تتغير كثير من مروج الأعشاب البحرية بنحو 1–2% كل عام، وتتراكم الخسائر الصغيرة لتصبح تراجعًا كبيرًا.

المصدر: Project Seagrass

بيان الأثر

حل منظمة غير ربحية · نشط

تفيد Project Seagrass بزراعة أكثر من 150,000 بذرة من الأعشاب البحرية وجمع أكثر من 3,000 نقطة بيانات جديدة عنها (أرقام المنظمة).

المصدر: Project Seagrass

لمزيد من المعلومات: Project Seagrass

الأعشاب البحرية ليست طحالب: إنها نباتات مزهرة تشكّل مروجًا تحت الماء.
