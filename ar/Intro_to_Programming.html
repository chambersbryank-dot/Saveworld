عن هذه الدورة

هذا مخطط دورة مجانية للتعلّم الذاتي كتبته Saving Planets. وهو ليس مقررًا جامعيًا، ولا يمنح ساعات معتمدة، ولا تشارك فيه أي مؤسسة تعليمية.

يتبع نطاقه مقررات البرمجة في السنة الأولى مثل MIT 6.100L (سابقًا 6.0001)، وCS50 في Harvard، وCS106A في Stanford، وCS 1371 في Georgia Tech للمهندسين. نضع روابط لمواد مجانية في كل مكان. لا تتبنى أي من هذه المؤسسات هذه الصفحة.

ما نضيفه: كل مثال هو كود بايثون حقيقي يشغّله نص البناء لدينا قبل نشر الصفحة، ويجب أن يطابق ناتجه المطبوع ما تراه هنا تمامًا. تأتي البيانات من مصادر عامة حقيقية: سجل CO₂ في ماونا لوا من NOAA، وتحليل درجات الحرارة GISTEMP من NASA، ومقاييس الأنهار من USGS.

لا تحتاج إلى تثبيت أي شيء: استخدم Google Colab أو JupyterLite، الذي يشغّل بايثون داخل متصفحك باستخدام Pyodide. يُحفظ تقدمك في هذا المتصفح فقط.

البداية: المتغيرات والأنواع والتعابير

شغّل أول كود بايثون لك في دفتر داخل المتصفح، وخزّن القيم في متغيرات، واحسب بالأرقام والنصوص.

أهداف التعلّم

في نهاية هذه الوحدة ستستطيع أن:

  • افتح دفتر Colab أو JupyterLite وشغّل الخلايا.
  • استخدم المتغيرات والأنواع int وfloat وstr وbool.
  • استخدم العوامل الحسابية، بما فيها // و% و**.
  • نسّق الناتج باستخدام f-strings.

المفاهيم الأساسية

  • البرنامج سلسلة من التعليمات. ويتيح لك الدفتر تشغيلها خلية بعد خلية ورؤية النتائج فورًا.
  • المتغير اسم مرتبط بقيمة: mass_kg = 1100. اختر أسماء تقول ما الشيء وبأي وحدات.
  • لكل قيمة نوع. int (الأعداد الصحيحة)، وfloat (الأعداد العشرية)، وstr (النص)، وbool (True/False) هي الأساسيات؛ وتخبرك type() بالنوع.
  • / يعطي دائمًا float؛ و// قسمة صحيحة؛ و% الباقي؛ و** القوة.
  • الأعداد float تقريبات ثنائية: 0.1 + 0.2 لا يساوي 0.3 تمامًا، لذا قارن قيم float بهامش تسامح.

التحكم في التدفق: الشروط والحلقات

اجعل البرامج تقرر باستخدام if/elif/else وتكرر باستخدام حلقات for وwhile.

أهداف التعلّم

في نهاية هذه الوحدة ستستطيع أن:

  • اكتب if/elif/else مع عوامل المقارنة والعوامل المنطقية.
  • كرّر على المجالات والتسلسلات باستخدام for.
  • استخدم حلقات while بشرط توقف واضح.
  • اجمع المجاميع والأعداد.

المفاهيم الأساسية

  • المسافة البادئة تحدد الكتل في بايثون. والمعيار أربع مسافات لكل مستوى.
  • المقارنات (<، >=، ==، !=) تنتج قيمًا منطقية؛ واجمعها بـ and وor وnot.
  • for x in sequence تتكرر مرة لكل عنصر؛ وrange(a, b) تعطي a، a+1، …، b−1.
  • while تتكرر حتى يصبح شرطها False. تأكد أن شيئًا داخل الحلقة يغيّره، وإلا فلن تنتهي أبدًا.
  • نمط المُراكِم: ابدأ المجموع من 0 وأضف داخل الحلقة.

الخوارزميات والتعقيد

البحث، وإيجاد الجذور، وكيف يزداد زمن التشغيل مع حجم المدخل: التفكير بترميز O الكبير.

أهداف التعلّم

في نهاية هذه الوحدة ستستطيع أن:

  • نفّذ البحث الخطي والبحث الثنائي.
  • استخدم التنصيف لحل المعادلات.
  • قدّر التعقيد: O(1)، O(log n)، O(n)، O(n²).
  • اختر هياكل البيانات من أجل السرعة.

المفاهيم الأساسية

  • الخوارزمية طريقة دقيقة خطوة بخطوة. وكلفتها هي كيف يزداد عدد الخطوات مع حجم المدخل n.
  • البحث الخطي يفحص العناصر واحدًا تلو الآخر: O(n). والبحث الثنائي ينصّف قائمة مرتبة في كل خطوة: O(log n).
  • يجد التنصيف جذرًا للدالة f على [a, b] حيث تغيّر f إشارتها، بتنصيف الفترة؛ وبعد n خطوة تصبح الفترة (b − a)/2ⁿ.
  • الحلقات المتداخلة على n عنصر هي O(n²): مقبولة لـ 1000 عنصر، وميؤوس منها لمليون.
  • البحث في القواميس والمجموعات O(1) في المتوسط، وفي القوائم O(n).

def linear_search(xs, target):
    for i, x in enumerate(xs):
        if x == target:
            return i
    return -1

def binary_search(xs, target):
    lo, hi, steps = 0, len(xs) - 1, 0
    while lo <= hi:
        steps += 1
        mid = (lo + hi) // 2
        if xs[mid] == target:
            return mid, steps
        if xs[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1, steps

def fly(v0, deg, k=0.0, dt=0.001, g=9.81):
    vx, vy = v0 * math.cos(math.radians(deg)), v0 * math.sin(math.radians(deg))
    x = y = 0.0
    while y >= 0:
        v = math.hypot(vx, vy)
        vx -= k * v * vx * dt
        vy -= (g + k * v * vy) * dt
        x += vx * dt
        y += vy * dt
    return x
