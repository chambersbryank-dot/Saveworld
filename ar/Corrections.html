الإبلاغ عن تصحيح

أخبرنا بما هو خطأ وسنصححه في كل اللغات. يمكنك الكتابة بأي لغة.

يُرجى عدم كتابة أسماء أو عناوين بريد إلكتروني أو أرقام هواتف. لا يمكننا الرد، ولا يُحفظ أي شيء ترسله على هذا الموقع.

يمكن للبالغين الذين لديهم حساب على GitHub فتح بلاغ عام على GitHub أيضًا.

ماذا يحدث بعد ذلك

نسعى للرد خلال 5 أيام عمل. وإذا كانت المعلومة خاطئة، نصححها في النسخ الأربع ونحدّث تاريخ «آخر مراجعة» للصفحة.

تُدرج التصحيحات المهمة (رقم أو تاريخ أو ادعاء خاطئ) أدناه مع تاريخ الإصلاح.
