How to Report an Error

Email errors@savingplanets.com with the page address, what is wrong and, if you can, a source. Any language is fine.

Report a correction

Tell us what is wrong and we will fix it in every language. Any language is fine.

Please don’t type names, emails or phone numbers. We can’t reply, and nothing you send is stored on this site.

Adults with a GitHub account can also open a public issue on GitHub.

What Happens Next

We aim to reply within 5 business days. If a fact is wrong, we fix it on all five language versions and update the page’s “Last reviewed” date.

Significant corrections (a wrong number, date or claim) are listed below with the date of the fix.
