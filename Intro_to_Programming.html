About this course

This is a free self-study course outline written by Saving Planets. It is not a university course, it carries no academic credit, and no school is involved.

Its scope follows first-year programming courses such as MIT 6.100L (formerly 6.0001), Harvard’s CS50, Stanford’s CS106A and Georgia Tech’s CS 1371 for engineers. We link to free materials throughout. None of these organizations endorse this page.

What we add: every example is real Python that our build script runs before the page goes live, and its printed output must match what you see here exactly. The data comes from real public sources: NOAA’s Mauna Loa CO₂ record, NASA’s GISTEMP temperature analysis and USGS river gauges.

You need nothing installed: use Google Colab or JupyterLite, which runs Python inside your browser with Pyodide. Your progress is saved only in this browser.

How this course helps save the planet

Climate and environmental science runs on code. The CO₂ curve, global temperature records and river forecasts are all built by programs reading public data, and you can read the same files.

Each unit ends with a short, sourced section showing how its ideas help people and the planet.

Before you start

Prerequisites

  • High-school algebra.
  • No programming experience needed.
  • Physics I and Calculus I help for the simulation unit but are not required.

How to study

  • Type every example yourself instead of pasting; your fingers learn syntax.
  • Predict the output before you run the code.
  • When stuck, read the error message from the bottom up.
  • Change one thing at a time and rerun.
  • Do every practice problem before opening the answer.
  • Retake the quizzes a few days later. Spaced practice beats one long session.

Lab equipment (for the wet labs)

  • A computer or tablet with a modern web browser.
  • A free Google account for Colab, or JupyterLite with no account at all.
  • Optional: Python 3 installed locally with NumPy and Matplotlib.

Unit 1 · Week 1

Getting Started: Variables, Types & Expressions

Run your first Python in a browser notebook, store values in variables, and compute with numbers and text.

Learning objectives

By the end of this unit you can:

  • Open a Colab or JupyterLite notebook and run cells.
  • Use variables and the types int, float, str and bool.
  • Use arithmetic operators, including //, % and **.
  • Format output with f-strings.

Key concepts

  • A program is a sequence of instructions. A notebook lets you run them one cell at a time and see results immediately.
  • A variable is a name bound to a value: mass_kg = 1100. Choose names that say what and in which units.
  • Every value has a type. int (whole numbers), float (decimals), str (text) and bool (True/False) are the basics; type() tells you which.
  • / always gives a float; // is floor division; % is the remainder; ** is a power.
  • Floats are binary approximations: 0.1 + 0.2 is not exactly 0.3, so compare floats with a tolerance.

Key equations

Worked examples, step by step

Example 1.1 Compute the weight of a 1,100 kg aircraft and check the types.

mass_kg = 1100
g = 9.81
weight = mass_kg * g
print(weight)
print(type(mass_kg), type(weight))
Show the steps
  1. mass_kg is an int; multiplying by the float g gives a float.

Output

10791.0
<class 'int'> <class 'float'>

Answer: 10,791 N, a float.

Example 1.2 How much has Mauna Loa CO₂ risen from the 1959 to the 2025 annual mean (NOAA)?

ppm_1959 = 315.98
ppm_2025 = 427.35
rise = ppm_2025 - ppm_1959
print(f"CO2 rose {rise:.2f} ppm, or {rise / ppm_1959:.1%}")
Show the steps
  1. Subtract, then divide by the starting value.
  2. The f-string formats :.2f (2 decimals) and :.1% (percent).

Output

CO2 rose 111.37 ppm, or 35.2%

Answer: 111.37 ppm, a 35.2% rise.

Example 1.3 Explore operators and float surprises.

print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
print(0.1 + 0.2 == 0.3, abs((0.1 + 0.2) - 0.3) < 1e-9)
print(int("42") + 1, str(42) + "1")
Show the steps
  1. 7/2 = 3.5, 7//2 = 3, 7%2 = 1.
  2. 0.1 + 0.2 == 0.3 is False; a tolerance test is True.
  3. int("42") converts text to a number; str(42) + "1" joins text.

Output

3.5 3 1 1024
False True
43 421

Answer: Use tolerances for floats and convert types on purpose.

Practice problems

Work each on paper first, then check.

  1. What does 17 % 5 give?

    Show answer

    2.

  2. What type is 3 * 2.0?

    Show answer

    float (6.0).

  3. Write an f-string that prints pi to 3 decimals.

    Show answer

    f"{math.pi:.3f}" → 3.142 (after import math).

  4. Why is mass_kg a better name than m?

    Show answer

    It states the quantity and its unit, preventing unit mistakes.

Common misconceptions

  • Myth: = means equals.

    Actually: In Python = assigns; == compares.

  • Myth: 0.1 + 0.2 == 0.3 is True.

    Actually: It is False because of binary rounding.

  • Myth: "5" + 5 gives 10.

    Actually: It is a TypeError; convert with int("5").

Flashcards

  • Variable

    Name bound to a value.

  • int / float

    Whole number / decimal number.

  • str

    Text.

  • bool

    True or False.

  • f-string

    f"{x:.2f}" formatting.

  • //, %

    Floor division, remainder.

Self-check quiz

1. 7 // 2 =

Show answer

3. Floor division.

Floor division.

2. type(2.0) is…

Show answer

float. It has a decimal point.

It has a decimal point.

3. 2 ** 10 =

Show answer

1024. Power.

Power.

4. Assignment in Python uses…

Show answer

=. = binds a name.

= binds a name.

How this helps save the planet

The numbers in Example 1.2 come straight from NOAA’s Global Monitoring Laboratory, which publishes the Mauna Loa CO₂ record as a free CSV file. A few lines of Python turn it into the headline facts of climate science.

Unit 2 · Week 2

Control Flow: Conditions & Loops

Make programs decide with if/elif/else and repeat with for and while loops.

Learning objectives

By the end of this unit you can:

  • Write if/elif/else with comparison and boolean operators.
  • Loop over ranges and sequences with for.
  • Use while loops with a clear stopping condition.
  • Accumulate totals and counts.

Key concepts

  • Indentation defines blocks in Python. Four spaces per level is standard.
  • Comparisons (<, >=, ==, !=) produce booleans; combine with and, or, not.
  • for x in sequence repeats once per item; range(a, b) gives a, a+1, …, b−1.
  • while repeats until its condition is False. Make sure something in the loop changes it, or it never ends.
  • The accumulator pattern: start a total at 0 and add inside the loop.

Key equations

Worked examples, step by step

Example 2.1 Classify NASA’s 2024 global temperature anomaly.

anomaly = 1.28   # NASA GISTEMP, 2024, deg C vs 1951-1980
if anomaly >= 1.0:
    print("at least 1.0 C above the 1951-1980 average")
elif anomaly > 0:
    print("warmer than average")
else:
    print("at or below average")
Show the steps
  1. 1.28 ≥ 1.0, so the first branch runs and the rest are skipped.

Output

at least 1.0 C above the 1951-1980 average

Answer: Branches are tested in order; only the first true one runs.

Example 2.2 Add the numbers 1 to 100 with a loop.

total = 0
for n in range(1, 101):
    total += n
print(total)
Show the steps
  1. range(1, 101) stops before 101.
  2. total += n adds each number.

Output

5050

Answer: 5,050, matching Gauss’s formula.

Example 2.3 If CO₂ kept rising 2.5 ppm a year from the 2025 mean, when would it pass 450 ppm?

ppm = 427.35   # 2025 annual mean, Mauna Loa
year = 2025
while ppm < 450:
    ppm += 2.5
    year += 1
print(year, round(ppm, 2))
Show the steps
  1. The loop adds 2.5 ppm and one year until ppm ≥ 450.

Output

2035 452.35

Answer: In 2035, at 452.35 ppm under this simple constant-rate scenario (not a forecast).

Practice problems

Work each on paper first, then check.

  1. How many times does for i in range(3, 10, 2) run?

    Show answer

    4 times (3, 5, 7, 9).

  2. Write a loop that counts the odd numbers below 20.

    Show answer

    count = sum(1 for n in range(20) if n % 2): 10.

  3. What is wrong with: while x < 10: print(x)

    Show answer

    x never changes, so it loops forever.

Common misconceptions

  • Myth: range(1, 10) includes 10.

    Actually: It stops at 9.

  • Myth: else after if is required.

    Actually: It is optional.

  • Myth: Indentation is just style.

    Actually: In Python it defines the program’s structure.

Flashcards

  • if / elif / else

    Choose one branch.

  • for

    Repeat per item.

  • while

    Repeat while true.

  • range(a, b, s)

    a up to b−1, step s.

  • Accumulator

    total += x in a loop.

  • break / continue

    Leave loop / skip to next pass.

Self-check quiz

1. list(range(2, 6)) is…

Show answer

[2, 3, 4, 5]. Stops before 6.

Stops before 6.

2. Which keyword adds another test after if?

Show answer

elif. elif.

elif.

3. A while loop stops when…

Show answer

its condition is False. Condition checked each pass.

Condition checked each pass.

4. not (True and False) is…

Show answer

True. True and False is False.

True and False is False.

How this helps save the planet

Thresholds like 1.0 °C or 450 ppm are exactly what monitoring programs test with if statements, flagging records and alerts automatically as new data arrives.

Unit 3 · Week 3

Functions

Package logic into reusable, testable functions with parameters, defaults and return values.

Learning objectives

By the end of this unit you can:

  • Define functions with def, parameters and return.
  • Use default and keyword arguments.
  • Write docstrings.
  • Understand local scope.

Key concepts

  • A function names a piece of logic. Write it once, test it once, use it everywhere.
  • Parameters receive values; return sends a result back. A function with no return gives None.
  • Default arguments (cl_max=1.6) make common cases short; keyword arguments make calls readable.
  • Variables created inside a function are local and vanish when it returns.
  • A docstring (the string on the first line) documents what the function does.

Key equations

Worked examples, step by step

Example 3.1 Write and test a Celsius-to-Fahrenheit function.

def c_to_f(c):
    """Convert Celsius to Fahrenheit."""
    return c * 9 / 5 + 32

for c in (-40, 0, 1.28, 100):
    print(c, "->", round(c_to_f(c), 2))
Show the steps
  1. −40 is the same on both scales, a handy check.
  2. round(…, 2) tidies the floats.

Output

-40 -> -40.0
0 -> 32.0
1.28 -> 34.3
100 -> 212.0

Answer: A 1.28 °C anomaly is a 2.3 °F difference, but 1.28 °C as a temperature is 34.3 °F; units matter.

Example 3.2 Turn the stall-speed formula into a function and use it at two densities.

def stall_speed(weight_n, rho, area, cl_max=1.6):
    return (2 * weight_n / (rho * area * cl_max)) ** 0.5

print(round(stall_speed(10791, 1.227, 16.2), 1))
print(round(stall_speed(10791, 0.738, 16.2), 1))
Show the steps
  1. cl_max has a default, so callers can omit it.
  2. ** 0.5 is a square root.

Output

26.0
33.6

Answer: 26.0 m/s at sea level and 33.6 m/s at 5,000 m, matching the aerospace course.

Example 3.3 Write a function that returns year-to-year changes of a list (Mauna Loa annual means 2022–2025).

def growth(values):
    """Year-to-year changes of a list."""
    return [b - a for a, b in zip(values, values[1:])]

co2 = [418.53, 421.08, 424.61, 427.35]   # 2022-2025
print([round(d, 2) for d in growth(co2)])
Show the steps
  1. zip pairs each value with the next.
  2. A list comprehension builds the result.

Output

[2.55, 3.53, 2.74]

Answer: Increases of 2.55, 3.53 and 2.74 ppm.

Practice problems

Work each on paper first, then check.

  1. Write area_circle(r) and test it at r = 2.

    Show answer

    return math.pi * r**2 → 12.566….

  2. What does a function without return give?

    Show answer

    None.

  3. Why test c_to_f at −40?

    Show answer

    Both scales agree there, so the expected answer is known.

Common misconceptions

  • Myth: print and return are the same.

    Actually: print shows a value; return hands it back for further use.

  • Myth: Changing a parameter changes the caller’s variable.

    Actually: Rebinding a parameter is local (mutable objects are an exception).

  • Myth: Functions should be long and do everything.

    Actually: Small, single-purpose functions are easier to test.

Flashcards

  • def

    Defines a function.

  • return

    Sends a value back.

  • Parameter

    Name for an input.

  • Default argument

    Value used if omitted.

  • Docstring

    Documentation string.

  • Scope

    Where a name is visible.

Self-check quiz

1. Define a function with…

Show answer

def. def name(params):

def name(params):

2. A function with no return statement returns…

Show answer

None. Implicit None.

Implicit None.

3. In def f(x, k=2), k is…

Show answer

a default argument. Has a default.

Has a default.

4. Variables made inside a function are…

Show answer

local. Local scope.

Local scope.

How this helps save the planet

Climate and hydrology codes are built from small, tested functions like these, for unit conversions, rates of change and physical formulas, which is how large models stay trustworthy.

Unit 4 · Week 4

Lists, Dictionaries & Strings

Store collections of data: lists for sequences, dictionaries for lookups, and strings for text.

Learning objectives

By the end of this unit you can:

  • Index, slice and modify lists.
  • Use len, sum, min, max and sorted.
  • Build and query dictionaries.
  • Split strings and count words.

Key concepts

  • A list holds an ordered sequence: flows[0] is the first item, flows[-1] the last, flows[2:5] a slice.
  • Lists are mutable: append, insert, remove and sort change them in place.
  • A dictionary maps keys to values: gistemp[2024] → 1.28. Lookups are fast no matter how big it is.
  • List comprehensions build lists concisely: [x * 2 for x in xs if x > 0].
  • Strings are sequences of characters with methods like split, strip, lower and startswith.

Key equations

Worked examples, step by step

Example 4.1 Summarize ten days of USGS daily mean flow for the Potomac at Little Falls (June 1–10, 2025, in cubic feet per second).

flows = [44700, 40200, 29100, 22700, 17300, 14100, 12600, 12200, 14300, 22600]
print(len(flows), max(flows), min(flows))
print(sum(flows) / len(flows))
print(sorted(flows)[:3])
Show the steps
  1. len, max and min work on any list.
  2. sum/len is the mean; sorted returns a new list.

Output

10 44700 12200
22980.0
[12200, 12600, 14100]

Answer: Mean 22,980 cfs; range 12,200–44,700 cfs.

Example 4.2 Find the warmest year in a dictionary of NASA GISTEMP anomalies.

gistemp = {2016: 1.01, 2020: 1.01, 2023: 1.17, 2024: 1.28, 2025: 1.18}
warmest = max(gistemp, key=gistemp.get)
print(warmest, gistemp[warmest])
print([y for y, a in gistemp.items() if a > 1.1])
Show the steps
  1. max with key=gistemp.get compares values.
  2. A comprehension filters items.

Output

2024 1.28
[2023, 2024, 2025]

Answer: 2024, at 1.28 °C; 2023–2025 are all above 1.1 °C.

Example 4.3 Count words with a dictionary.

words = "reduce reuse recycle reduce repair reduce".split()
counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
print(counts)
Show the steps
  1. get(w, 0) returns 0 for a new word.

Output

{'reduce': 3, 'reuse': 1, 'recycle': 1, 'repair': 1}

Answer: “reduce” appears 3 times.

Practice problems

Work each on paper first, then check.

  1. What is [10, 20, 30, 40][1:3]?

    Show answer

    [20, 30].

  2. How do you add 2026: 1.2 to gistemp?

    Show answer

    gistemp[2026] = 1.2.

  3. Square each number in xs with a comprehension.

    Show answer

    [x**2 for x in xs].

Common misconceptions

  • Myth: Lists start at index 1.

    Actually: They start at 0.

  • Myth: sorted(xs) changes xs.

    Actually: sorted returns a new list; xs.sort() changes it.

  • Myth: Dictionary keys can repeat.

    Actually: Each key is unique; assigning again replaces the value.

Flashcards

  • List

    Ordered, mutable sequence.

  • Index / slice

    xs[i], xs[a:b].

  • Dictionary

    Key → value map.

  • Comprehension

    [f(x) for x in xs if cond].

  • Tuple

    Immutable sequence.

  • str.split

    Text → list of pieces.

Self-check quiz

1. xs[-1] is…

Show answer

the last item. Negative indices count from the end.

Negative indices count from the end.

2. len({"a": 1, "b": 2}) =

Show answer

2. Two keys.

Two keys.

3. "a,b,c".split(",") gives…

Show answer

["a", "b", "c"]. A list of strings.

A list of strings.

4. Lists are…

Show answer

mutable. They can change in place.

They can change in place.

How this helps save the planet

USGS publishes daily streamflow for thousands of river gauges. The ten numbers in Example 4.1 are real: a high-flow pulse on the Potomac receding over a week, the kind of record used for water supply and flood planning.

Unit 5 · Weeks 5–6

Files & CSV Data

Read and write files, parse CSV data, and handle messy rows without crashing.

Learning objectives

By the end of this unit you can:

  • Open, read and write text files with with.
  • Parse CSV with the csv module.
  • Convert strings to numbers and handle errors with try/except.
  • Download a real dataset and analyze it.

Key concepts

  • with open(name) as f: opens a file and closes it automatically.
  • CSV (comma-separated values) is the most common format for public data. csv.DictReader turns each row into a dictionary keyed by the header.
  • Everything read from a file is text: convert with int() and float().
  • Real data has comments, blanks and bad values. try/except ValueError lets you skip or log them.
  • NOAA’s Mauna Loa annual-mean file starts with # comment lines, then year,mean,unc.

Key equations

Worked examples, step by step

Example 5.1 Parse the last five rows of NOAA’s Mauna Loa annual-mean CSV and find the average rate of rise.

import csv, io
text = """year,mean,unc
2021,416.41,0.12
2022,418.53,0.12
2023,421.08,0.12
2024,424.61,0.12
2025,427.35,0.12
"""
rows = list(csv.DictReader(io.StringIO(text)))
years = [int(r["year"]) for r in rows]
ppm = [float(r["mean"]) for r in rows]
print(years[0], years[-1], ppm[-1])
print(round((ppm[-1] - ppm[0]) / (years[-1] - years[0]), 2), "ppm per year")
Show the steps
  1. io.StringIO lets csv read a string as if it were a file.
  2. Convert the text fields to int and float.

Output

2021 2025 427.35
2.73 ppm per year

Answer: 2.73 ppm per year from 2021 to 2025.

Example 5.2 Write a small CSV of USGS flows, read it back and convert to m³/s.

with open("flows.csv", "w") as f:
    f.write("date,cfs\n2025-06-01,44700\n2025-06-02,40200\n2025-06-03,29100\n")
with open("flows.csv") as f:
    next(f)                      # skip the header
    for line in f:
        date, cfs = line.strip().split(",")
        print(date, round(int(cfs) * 0.0283168, 1), "m3/s")
Show the steps
  1. next(f) skips the header line.
  2. strip removes the newline; split separates fields.

Output

2025-06-01 1265.8 m3/s
2025-06-02 1138.3 m3/s
2025-06-03 824.0 m3/s

Answer: 44,700 cfs ≈ 1,265.8 m³/s.

Example 5.3 Read lines with comments and bad values without crashing.

lines = ["# comment", "year,mean", "2024,424.61", "2025,bad", "2026,"]
good = []
for line in lines:
    if line.startswith("#") or line.startswith("year"):
        continue
    year, value = line.split(",")
    try:
        good.append((int(year), float(value)))
    except ValueError:
        print("skipping", repr(line))
print(good)
Show the steps
  1. continue skips comments and the header.
  2. float("bad") and float("") raise ValueError, which is caught.

Output

skipping '2025,bad'
skipping '2026,'
[(2024, 424.61)]

Answer: Only the valid row is kept; the bad ones are reported.

Practice problems

Work each on paper first, then check.

Unit 8 · Weeks 10–11

Algorithms & Complexity

Searching, root finding and how running time grows with input size: big-O thinking.

Learning objectives

By the end of this unit you can:

  • Implement linear and binary search.
  • Use bisection to solve equations.
  • Estimate complexity: O(1), O(log n), O(n), O(n²).
  • Choose data structures for speed.

Key concepts

  • An algorithm is a precise step-by-step method. Its cost is how the number of steps grows with the input size n.
  • Linear search checks items one by one: O(n). Binary search halves a sorted list each step: O(log n).
  • Bisection finds a root of f on [a, b] where f changes sign by halving the interval; after n steps the interval is (b − a)/2ⁿ.
  • Nested loops over n items are O(n²): fine for 1,000 items, hopeless for a million.
  • Dictionary and set lookups are O(1) on average, list searches O(n).

Key equations

Worked examples, step by step

Example 8.1 Search a sorted list of one million even numbers for the last one, both ways.

def linear_search(xs, target):
    for i, x in enumerate(xs):
        if x == target:
            return i
    return -1

def binary_search(xs, target):
    lo, hi, steps = 0, len(xs) - 1, 0
    while lo <= hi:
        steps += 1
        mid = (lo + hi) // 2
        if xs[mid] == target:
            return mid, steps
        if xs[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1, steps

data = list(range(0, 2_000_000, 2))
print(linear_search(data, 1_999_998))
print(binary_search(data, 1_999_998))
Show the steps
  1. Linear search checks 1,000,000 items to reach index 999,999.
  2. Binary search needs only 20 steps.

Output

999999
(999999, 20)

Answer: 20 steps versus a million: log₂(10⁶) ≈ 20.

Example 8.2 Find √2 by bisection on x² − 2 from [0, 2] to 10⁻⁶.

def bisect_root(f, a, b, tol=1e-6):
    n = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
        n += 1
    return (a + b) / 2, n

root, n = bisect_root(lambda x: x**2 - 2, 0, 2)
print(round(root, 6), n)
Show the steps

  2. 2/2²¹ < 10⁻⁶ after 21 steps.

Answer: 1.414214 after 21 iterations.

Unit 9 · Weeks 12–14

Numerical Simulation

Step physical models forward in time: a projectile, an orbit and a population, the core of every climate and engineering model.

Learning objectives

By the end of this unit you can:

  • Use time-stepping (Euler and Euler-Cromer) to simulate motion.
  • Check simulations against exact answers.
  • Simulate a circular orbit and a logistic population.
  • Explore how step size affects accuracy.

Key concepts

  • A simulation updates the state (position, velocity, population) in small time steps dt using the rates of change: x_new = x + v·dt.
  • Euler-Cromer updates velocity first, then position with the new velocity; it keeps orbits stable much better than plain Euler.
  • Always validate: compare with an exact solution in a case where one exists (no air drag, circular orbit, logistic formula).
  • Smaller dt is more accurate but slower; halve dt and see whether the answer changes.
  • Weather and climate models are vast versions of these loops, stepping the equations of physics across a global grid.

Key equations

Worked examples, step by step

Example 9.1 Simulate a 20 m/s projectile at 45° and compare with the exact range.

import math
v0, angle, g, dt = 20.0, math.radians(45), 9.81, 0.001
x, y = 0.0, 0.0
vx, vy = v0 * math.cos(angle), v0 * math.sin(angle)
while y >= 0:
    vy -= g * dt
    x += vx * dt
    y += vy * dt
print(round(x, 2), "m simulated;", round(v0**2 / g, 2), "m exact")
Show the steps
  1. Step velocity, then position, until it lands.
  2. Exact range = v₀² sin 90°/g.

Output

40.77 m simulated; 40.77 m exact

Answer: Both give 40.77 m to two decimals with dt = 0.001 s.

Example 9.2 Simulate one orbit 400 km above Earth with 1-second steps.

import math
GM = 3.986e14
r0 = 6.771e6
x, y = r0, 0.0
vx, vy = 0.0, math.sqrt(GM / r0)
dt, t = 1.0, 0
period = 2 * math.pi * math.sqrt(r0**3 / GM)
while t < period:
    r3 = (x * x + y * y) ** 1.5
    vx -= GM * x / r3 * dt          # Euler-Cromer: update velocity first
    vy -= GM * y / r3 * dt
    x += vx * dt
    y += vy * dt
    t += dt
print(round(period / 60, 1), "min;", round(math.hypot(x, y) / 1000), "km from Earth's center")
Show the steps
  1. Start at r₀ with circular speed √(GM/r₀).
  2. Update velocity from gravity, then position.

Output

92.4 min; 6771 km from Earth's center

Answer: After one period (92.4 minutes) the spacecraft is still 6,771 km from Earth’s center: the orbit stays circular.

Lab D: Projectile with air drag

Week 14

Goal: Extend the projectile simulation with quadratic drag and find the best launch angle as drag increases.

Procedure

  1. Run the starter code, which searches whole-degree angles from 20° to 60°.
  2. Check that k = 0 gives 45° and the exact range.
  3. Halve dt and confirm the results barely change.
  4. Plot range against angle for each k.
import math
def fly(v0, deg, k=0.0, dt=0.001, g=9.81):
    vx, vy = v0 * math.cos(math.radians(deg)), v0 * math.sin(math.radians(deg))
    x = y = 0.0
    while y >= 0:
        v = math.hypot(vx, vy)
        vx -= k * v * vx * dt
        vy -= (g + k * v * vy) * dt
        x += vx * dt
        y += vy * dt
    return x
for k in (0.0, 0.01, 0.05):
    best = max(range(20, 61), key=lambda a: fly(20, a, k))
    print(k, best, round(fly(20, best, k), 1))
