על הקורס

זהו מתווה של קורס חינמי ללימוד עצמי שנכתב על ידי Saving Planets. הוא אינו קורס אוניברסיטאי, אינו מעניק נקודות זכות אקדמיות, ואף מוסד לימודים אינו מעורב בו.

היקפו תואם סמסטר ראשון של חשבון אינפיניטסימלי באוניברסיטה (חשבון דיפרנציאלי במשתנה אחד ומבוא לאינטגרלים), לפי הנושאים והעומק של חומרים פתוחים כמו OpenStax Calculus Volume 1 ו-MIT OpenCourseWare 18.01SC Single Variable Calculus, שאליהם אנו מקשרים לאורך הקורס. ארגונים אלה אינם ממליצים על דף זה.

מה שאנחנו מוסיפים: כל יחידה מחברת את החשבון האינפיניטסימלי לבעיות אמיתיות של אקלים, אנרגיה וטיסות חלל, כל מספר בדף מחושב מחדש בסקריפט בדיקה לפני הפרסום, וארבע מעבדות מחשב מאפשרות לכם לעבוד עם נתונים כמו מדענים ומהנדסים.

עברו עליו לפי הסדר. בכל יחידה יש מטרות, רעיונות מרכזיים, משוואות, דוגמאות צעד אחר צעד, תרגול עם תשובות מלאות, טעויות נפוצות, כרטיסיות ובוחן. ההתקדמות שלכם נשמרת רק בדפדפן הזה.

איך הקורס הזה עוזר להציל את כדור הארץ

חשבון אינפיניטסימלי הוא המתמטיקה של השינוי. מדעני אקלים משתמשים בנגזרות כדי להפוך רשומה של פחמן דו-חמצני או קרח ים לקצב שינוי, מהנדסים משתמשים באופטימיזציה כדי להפיק את מרב האנרגיה מהרוח ואת מרב המשימה מכל קילוגרם של דלק טילים, ואינטגרלים מסכמים הספק לאנרגיה.

כל יחידה מסתיימת בקטע קצר עם מקורות שמראה איך הרעיונות שלה עוזרים גם לאנשים וגם לטבע.

יחידה 1 · שבועות 1–3

פונקציות וגבולות

גבול מתאר למה פונקציה מתקרבת. זה הרעיון שעומד מתחת לכל נגזרת ולכל אינטגרל.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • להעריך גבולות מגרפים ומטבלאות, כולל גבולות חד-צדדיים.
  • לחשב גבולות בעזרת חוקי הגבולות, פירוק לגורמים והכפלה בצמוד.
  • למצוא גבולות באינסוף ולזהות אסימפטוטות אופקיות ואנכיות.
  • לנסח את ההגדרה המדויקת (ε–δ) של גבול.

מושגי מפתח

  • lim f(x) כאשר x → a = L פירושו שאפשר לקרב את f(x) ל-L ככל שנרצה על ידי בחירת x קרוב מספיק ל-a, אך שונה מ-a.
  • גבול קיים רק אם הגבולות משמאל ומימין שווים.
  • בצורה 0/0, פשטו קודם: פרקו לגורמים, צמצמו או הכפילו בצמוד.
  • שני גבולות מיוחדים: sin x / x → 1 ו-(1 − cos x)/x → 0 כאשר x → 0 (x ברדיאנים).
  • באינסוף, השוו את החזקות הגבוהות ביותר בפונקציה רציונלית.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

דוגמה 1.1 מצאו את lim (x² − 4)/(x − 2) כאשר x → 2.

הצג את השלבים
  1. הצבה ישירה נותנת 0/0, לכן פשטו.
  2. (x² − 4)/(x − 2) = (x − 2)(x + 2)/(x − 2) = x + 2 עבור x ≠ 2.
  3. עכשיו הציבו: 2 + 2 = 4.

תשובה: 4.

דוגמה 1.2 מצאו את lim (√(x + 4) − 2)/x כאשר x → 0.

הצג את השלבים
  1. שוב 0/0. הכפילו את המונה והמכנה בצמוד √(x + 4) + 2.
  2. המונה הופך ל-(x + 4) − 4 = x, ולכן הביטוי הוא 1/(√(x + 4) + 2).
  3. הציבו x = 0: ‏1/(2 + 2) = 1/4.

תשובה: 1/4.

דוגמה 1.3 מצאו את lim (3x² + 1)/(2x² − 5) כאשר x → ∞.

הצג את השלבים
  1. חלקו את המונה והמכנה ב-x²: ‏(3 + 1/x²)/(2 − 5/x²).
  2. As x → ∞, 1/x² → 0.

תשובה: 3/2, ולכן y = 3/2 היא אסימפטוטה אופקית.

תרגילים

פתרו כל אחד קודם על נייר, ואז בדקו.

  1. lim (x² − 9)/(x − 3) כאשר x → 3

    הצג תשובה

    פרקו לגורמים: x + 3 → 6.

  2. lim (5x + 2)/(x − 1) כאשר x → ∞

    הצג תשובה

    חלקו ב-x: ‏5.

  3. lim (1 − cos x)/x כאשר x → 0

    הצג תשובה

    0 (גבול מוכר).

  4. lim 1/x כאשר x → 0⁺ וכאשר x → 0⁻

    הצג תשובה

    ‎+∞ מימין, ‎−∞ משמאל, ולכן הגבול הדו-צדדי אינו קיים.

  5. lim sin(3x)/x כאשר x → 0

    הצג תשובה

    כתבו זאת כ-3 · sin(3x)/(3x) → 3 × 1 = 3.

תפיסות שגויות נפוצות

  • מיתוס: גבול הוא פשוט ערך הפונקציה באותה נקודה.

    בפועל: הגבול מתעלם מ-f(a). ‏f יכולה להיות לא מוגדרת ב-a ועדיין להיות לה שם גבול, כמו בדוגמה 1.1.

  • מיתוס: 0/0 פירושו שהגבול הוא 0 (או שאינו קיים).

    בפועל: 0/0 היא צורה לא מוגדרת: הגבול יכול להיות כל דבר. צריך לפשט.

  • מיתוס: אם הגרף מתקרב לישר, הוא לעולם לא יכול לחצות אותו.

    בפועל: גרף יכול לחצות אסימפטוטה אופקית; האסימפטוטה מתארת את ההתנהגות הרחק.

כרטיסיות

  • גבול

    הערך ש-f(x) מתקרבת אליו כאשר x מתקרב ל-a.

  • גבול חד-צדדי

    גבול משמאל (x → a⁻) או מימין (x → a⁺).

  • צורה לא מוגדרת

    0/0 או ∞/∞: פשטו לפני שמחליטים.

  • אסימפטוטה אופקית

    y = L כאשר f(x) → L כש-x → ±∞.

  • אסימפטוטה אנכית

    x = a כאשר f(x) → ±∞ כש-x → a.

  • הגדרת ε–δ

    לכל ε > 0 קיים δ > 0 ששומר את f(x) במרחק פחות מ-ε מ-L.

רציפות ונגזרת

רציפות פירושה שאין קטיעות. הנגזרת היא הגבול של קצבי השינוי הממוצעים: השיפוע של המשיק.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לבדוק רציפות של פונקציה ולהשתמש במשפט ערך הביניים.
  • לחשב נגזרת מתוך הגדרת הגבול.
  • לפרש נגזרת כשיפוע, כמהירות וכקצב שינוי, עם יחידות.
  • לכתוב משוואה של ישר משיק.

מושגי מפתח

  • f רציפה ב-a אם f(a) מוגדרת, הגבול קיים והם שווים.
  • משפט ערך הביניים: פונקציה רציפה ב-[a, b] מקבלת כל ערך בין f(a) ל-f(b).
  • הנגזרת f′(a) היא הגבול של מנת ההפרשים [f(a + h) − f(a)]/h כאשר h → 0.
  • היחידות של f′ הן יחידות f ליחידת x: מטר לשנייה, ppm לשנה.
  • פונקציה אינה גזירה בפינה, בחוד, במשיק אנכי או בקטיעה.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

דוגמה 2.1 השתמשו בהגדרה כדי למצוא את הנגזרת של f(x) = x².

הצג את השלבים
  1. [(x + h)² − x²]/h = (2xh + h²)/h = 2x + h.
  2. כאשר h → 0 זה שואף ל-2x.

תשובה: f′(x) = 2x.

דוגמה 2.2 מצאו את המשיק ל-y = x³ ב-x = 1.

הצג את השלבים
  1. y′ = 3x², ולכן השיפוע ב-x = 1 הוא 3.
  2. נקודה: (1, 1).
  3. y − 1 = 3(x − 1), ולכן y = 3x − 2.

תשובה: y = 3x − 2.

דוגמה 2.3 לאיזה a הפונקציה f(x) = x + 1 (x < 1), ax² (x ≥ 1) רציפה בכל מקום?

הצג את השלבים
  1. גבול משמאל ב-1: ‏1 + 1 = 2.
  2. ערך וגבול מימין: a × 1² = a.
  3. רציפות מחייבת a = 2.

תשובה: a = 2.

  1. השתמשו בהגדרה כדי לגזור את f(x) = 1/x.

    הצג תשובה

    [1/(x + h) − 1/x]/h = −1/(x(x + h)) → −1/x².

  2. אבן שמופלת נופלת s(t) = 4.9t² מטרים. מצאו את מהירותה הממוצעת מ-t = 1 עד t = 3 s ואת מהירותה הרגעית ב-t = 2 s.

    הצג תשובה

    הצג תשובה

    f(0) = −1 < 0 ו-f(1) = 1 > 0, ו-f רציפה, ולכן לפי משפט ערך הביניים היא חוצה את 0 ביניהם.

  4. האם f(x) = |x| גזירה ב-0?

    הצג תשובה

    לא. השיפוע הוא ‎−1 משמאל ו-‎+1 מימין, ולכן הגבול של מנת ההפרשים אינו קיים (פינה).

תפיסות שגויות נפוצות

  • מיתוס: רציפה פירושה גזירה.

    בפועל: |x| רציפה ב-0 אך אין לה שם נגזרת. לעומת זאת, גזירה כן גוררת רציפה.

  • מיתוס: הנגזרת היא השינוי ב-y.

    בפועל: זה קצב השינוי: שינוי ב-y ליחידת שינוי ב-x, בגבול.

  • מיתוס: המשיק נוגע בעקומה בנקודה אחת בלבד.

    בפועל: הוא יכול לחצות את העקומה במקום אחר, ואפילו בנקודת ההשקה (כמו y = x³ ב-0).

כרטיסיות

  • רציפות ב-a

  • משפט ערך הביניים

  • מנת הפרשים

    [f(x + h) − f(x)]/h, קצב שינוי ממוצע.

  • נגזרת

    הגבול של מנת ההפרשים; קצב שינוי רגעי.

  • משיק

    y = f(a) + f′(a)(x − a).

  • גזירה ⇒ רציפה

    אבל לא להפך.

כללי גזירה

כללי החזקה, המכפלה, המנה והשרשרת, וגם נגזרות של פונקציות טריגונומטריות, מעריכיות ולוגריתמיות, וגזירה סתומה.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לגזור פולינומים, מכפלות, מנות והרכבות במהירות ובדיוק.
  • לגזור sin, cos, tan, eˣ ו-ln x.
  • להשתמש בגזירה סתומה כדי למצוא dy/dx.
  • למצוא נגזרות מסדר גבוה ולפרש את הנגזרת השנייה כתאוצה.

מושגי מפתח

  • כלל החזקה: d/dx xⁿ = nxⁿ⁻¹ לכל n ממשי.
  • כלל המכפלה: (fg)′ = f′g + fg′. כלל המנה: (f/g)′ = (f′g − fg′)/g².
  • כלל השרשרת: הנגזרת של f(g(x)) היא f′(g(x)) · g′(x), נגזרת חיצונית כפול נגזרת פנימית.

  • גזירה סתומה: גזרו את שני האגפים לפי x, כאשר y מטופל כפונקציה של x.

יישומים I: קצבים קשורים, קירוב ושיטת ניוטון

להשתמש בנגזרות כדי לקשר בין גדלים משתנים, לקרב ערכים קשים, לחשב גבולות מסובכים ולפתור משוואות באופן מספרי.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לפתור בעיות של קצבים קשורים.
  • להשתמש בקירוב לינארי ובדיפרנציאלים כדי להעריך ערכים ושגיאות.
  • להחיל את כלל לופיטל על צורות 0/0 ו-∞/∞.
  • לפתור משוואות בשיטת ניוטון.

מושגי מפתח

  • קצבים קשורים: כתבו משוואה שמקשרת בין הגדלים, גזרו לפי הזמן, ואז הציבו ערכים.
  • ליד x = a, ‏f(x) ≈ f(a) + f′(a)(x − a): המשיק הוא ההערכה הטובה ביותר בקו ישר.
  • כלל לופיטל: עבור 0/0 או ∞/∞, ‏lim f/g = lim f′/g′ אם האגף הימני קיים.
  • שיטת ניוטון: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). בדרך כלל היא מתכנסת מהר מאוד מניחוש התחלתי טוב.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

הצג את השלבים

תשובה: בערך 2,510 cm³/s.

הצג את השלבים
  1. f(x) = √x, a = 4: f(4) = 2, f′(4) = 1/(2√4) = 1/4.
  2. L(4.1) = 2 + (1/4)(0.1) = 2.025.

תשובה: 2.025 (הערך האמיתי הוא 2.02485…).

דוגמה 4.3 השתמשו בשיטת ניוטון כדי לפתור x² = 2 החל מ-x₀ = 1.

הצג את השלבים
  1. f(x) = x² − 2, f′(x) = 2x, ולכן xₙ₊₁ = xₙ − (xₙ² − 2)/(2xₙ).
  2. x₁ = 1.5, x₂ = 1.416667, x₃ = 1.414216.

פתרו כל אחד קודם על נייר, ואז בדקו.

  1. סולם באורך 5 m מחליק לאורך קיר; הבסיס שלו מתרחק ב-0.5 m/s. באיזו מהירות יורד הקצה העליון כאשר הבסיס נמצא 3 m מהקיר?

    הצג תשובה

    הצג תשובה

  3. שיטת ניוטון עבור x³ − 2x − 5 = 0 החל מ-x₀ = 2. מצאו את x₁ ו-x₂.

    הצג תשובה

  4. השתמשו בדיפרנציאלים כדי להעריך את השינוי בשטח של דיסקה ברדיוס 10 cm אם הרדיוס גדל ב-0.1 cm.

    הצג תשובה

יישומים II: קיצון, צורת הגרף ואופטימיזציה

למצוא מקסימום ומינימום, לקרוא את צורת הגרף מתוך f′ ו-f″, ולפתור בעיות תכנון אמיתיות באופטימיזציה.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • למצוא נקודות קריטיות וקיצון מוחלט בקטע סגור.
  • לנסח את משפט הערך הממוצע ולהשתמש בו.
  • להשתמש במבחני הנגזרת הראשונה והשנייה ולמצוא נקודות פיתול.
  • לנסח ולפתור בעיות אופטימיזציה שימושיות.

מושגי מפתח

  • נקודות קריטיות הן היכן ש-f′ = 0 או ש-f′ אינה קיימת. הקיצון של פונקציה חלקה מתקבל שם או בקצוות.
  • משפט הערך הממוצע: בקטע חלק, הקצב הרגעי שווה לקצב הממוצע בנקודה כלשהי.
  • f′ > 0 פירושו עולה; f″ > 0 פירושו קעורה כלפי מעלה. נקודת פיתול היא היכן שהקעירות מתחלפת.
  • מתכון לאופטימיזציה: שרטטו, כתבו את הגודל שרוצים לייעל כפונקציה של משתנה אחד בעזרת האילוץ, גזרו, מצאו נקודות קריטיות ובדקו את הקצוות.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

דוגמה 5.1 מצאו את נקודות הקיצון המקומיות של f(x) = x³ − 3x.

הצג את השלבים
  1. f′(x) = 3x² − 3 = 0 עבור x = ±1.
  2. f″(x) = 6x: ‏f″(−1) = −6 < 0 (מקסימום), f″(1) = 6 > 0 (מינימום).
  3. f(−1) = 2, f(1) = −2.

תשובה: מקסימום מקומי 2 ב-x = −1; מינימום מקומי ‎−2 ב-x = 1.

דוגמה 5.2 פחית גלילית סגורה צריכה להכיל 500 cm³. איזה רדיוס דורש הכי מעט מתכת?

הצג את השלבים
  1. אילוץ: πr²h = 500, ולכן h = 500/(πr²).
  2. שטח A = 2πr² + 2πrh = 2πr² + 1000/r.
  3. A′ = 4πr − 1000/r² = 0 נותן r³ = 500/(2π), ‏r = 4.30 cm.
  4. אז h = 8.60 cm = 2r, ו-A = 349 cm².

תשובה: r = 4.30 cm, h = 8.60 cm (הגובה שווה לקוטר).

דוגמה 5.3 במודל הפשוט ביותר של טורבינת רוח, החלק של הספק הרוח שנלכד הוא Cp = 4a(1 − a)², כאשר a הוא מידת ההאטה של הרוח על ידי הרוטור. מצאו את המקסימום.

הצג את השלבים
  1. Cp′ = 4(1 − a)² − 8a(1 − a) = 4(1 − a)(1 − 3a).
  2. נקודות קריטיות a = 1 ו-a = 1/3; ‏a = 1 נותן Cp = 0.
  3. Cp(1/3) = 4 × (1/3) × (2/3)² = 16/27 = 0.593.

תשובה: 59.3%: גבול בץ, המקסימום התאורטי לכל טורבינת רוח.

תרגילים

פתרו כל אחד קודם על נייר, ואז בדקו.

  1. לחקלאי יש 100 m גדר לשלוש צלעות של מלבן לאורך נהר. מהו השטח הגדול ביותר?

    הצג תשובה

    A = x(100 − 2x); ‏A′ = 100 − 4x = 0 ב-x = 25. שטח = 25 × 50 = 1,250 m².

  2. מצאו את המקסימום והמינימום המוחלטים של f(x) = x² − 4x בקטע [0, 5].

    הצג תשובה

    נקודה קריטית x = 2: ‏f = −4. קצוות: f(0) = 0, f(5) = 5. מקסימום 5, מינימום ‎−4.

  3. אמתו את משפט הערך הממוצע עבור f(x) = x² בקטע [1, 3].

    הצג תשובה

    קצב ממוצע (9 − 1)/2 = 4; ‏f′(c) = 2c = 4 ב-c = 2, בתוך [1, 3].

  4. היכן f(x) = x³ − 6x² קעורה כלפי מעלה?

    הצג תשובה

    f″ = 6x − 12 > 0 כאשר x > 2; נקודת פיתול ב-x = 2.

תפיסות שגויות נפוצות

    בפועל: ל-x³ יש f′(0) = 0 אבל אין שם קיצון.

  • מיתוס: המקסימום המוחלט תמיד נמצא בנקודה קריטית.

    בפועל: בקטע סגור הוא יכול להיות בקצה. תמיד בדקו אותם.

  • מיתוס: קעורה כלפי מעלה פירושה עולה.

    בפועל: הקעירות קשורה ל-f″; פונקציה יכולה להיות קעורה כלפי מעלה ויורדת, כמו e⁻ˣ.

כרטיסיות

  • נקודה קריטית

    f′ = 0 או לא מוגדרת.

  • משפט ערכי הקיצון

  • משפט הערך הממוצע

  • מבחן הנגזרת הראשונה

    החלפת סימן של f′ מ-+ ל-− היא מקסימום; מ-− ל-+ היא מינימום.

  • קעירות

    f″ > 0 כלפי מעלה, f″ < 0 כלפי מטה.

  • גבול בץ

    Cp מרבי = 16/27 ≈ 59.3%.

אינטגרלים והמשפט היסודי של החשבון האינפיניטסימלי

אינטגרלים מסכמים חלקים זעירים: שטח, מרחק, אנרגיה. המשפט היסודי מקשר אותם לנגזרות.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לקרב שטחים בסכומי רימן ובכלל הטרפז.
  • להגדיר את האינטגרל המסוים ולהשתמש בתכונותיו.
  • להשתמש בשני חלקי המשפט היסודי של החשבון האינפיניטסימלי.
  • למצוא פונקציות קדומות, כולל בהצבה, ולחשב שינוי נטו, ערך ממוצע ושטחים בין עקומות.

מושגי מפתח

  • סכום רימן מסכם f(xᵢ)Δx על פני פרוסות קטנות; האינטגרל המסוים הוא הגבול שלו כשהפרוסות מצטמצמות.
  • המשפט היסודי, חלק 1: d/dx ∫ₐˣ f(t) dt = f(x). אינטגרציה וגזירה מבטלות זו את זו.
  • המשפט היסודי, חלק 2: ∫ₐᵇ f(x) dx = F(b) − F(a) לכל פונקציה קדומה F.
  • משפט השינוי נטו: אינטגרציה של קצב נותנת את השינוי הכולל. אינטגרציה של הספק נותנת אנרגיה; של מהירות נותנת העתק.
  • הצבה היא כלל השרשרת בכיוון ההפוך.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

דוגמה 6.1 חשבו את ∫₀² x² dx.

הצג את השלבים
  1. פונקציה קדומה x³/3.
  2. 8/3 − 0 = 8/3.

תשובה: 8/3 ≈ 2.667.

דוגמה 6.2 חשבו את ∫₀¹ 2x(x² + 1)³ dx.

הצג את השלבים
  1. נציב u = x² + 1, ‏du = 2x dx; ‏u נע מ-1 עד 2.
  2. ∫₁² u³ du = [u⁴/4]₁² = (16 − 1)/4.

תשובה: 15/4 = 3.75.

דוגמה 6.3 ביום בהיר, תפוקה של מערך סולארי מתוארת כ-P(t) = 5 sin(πt/12) kW עבור 0 ≤ t ≤ 12 שעות אחרי הזריחה. כמה אנרגיה הוא מפיק?

הצג את השלבים
  1. אנרגיה = ∫₀¹² 5 sin(πt/12) dt.
  2. פונקציה קדומה: −(60/π) cos(πt/12).
  3. −(60/π)(cos π − cos 0) = 120/π.

תשובה: 120/π ≈ 38.2 kWh (מודל מפושט, לא מערך אמיתי).

  1. ∫₀^π sin x dx

    הצג תשובה

    [−cos x]₀^π = 1 + 1 = 2.

  2. d/dx ∫₀ˣ cos(t²) dt

    הצג תשובה

    cos(x²), לפי חלק 1 של המשפט היסודי.

  3. מהירות העלייה של טיל היא v(t) = 9.8t m/s במשך 3 s. לאיזה גובה הוא עולה?

    הצג תשובה

    ∫₀³ 9.8t dt = 4.9 × 9 = 44.1 m.

  4. מצאו את השטח בין y = x ל-y = x² בקטע [0, 1].

    הצג תשובה

    הצג תשובה

    (1/3) ∫₀³ x² dx = (1/3)(9) = 3.

  • מיתוס: אינטגרל הוא תמיד שטח, ולכן הוא תמיד חיובי.

    בפועל: זה שטח מסומן: חלקים מתחת לציר נחשבים שליליים. ∫₀^{2π} sin x dx = 0.

  • מיתוס: לשכוח את ה-‎+ C לא משנה.

    בפועל: באינטגרלים לא מסוימים הקבוע הוא חלק מהתשובה; הוא חשוב בכל פעם שניתן תנאי התחלה.

  • מיתוס: בהצבה, השאירו את הגבולות הישנים.

    בפועל: החליפו את הגבולות לערכי u, או הציבו חזרה לפני החישוב.
