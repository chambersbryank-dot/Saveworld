על הקורס

זהו מתווה של קורס חינמי ללימוד עצמי שנכתב על ידי Saving Planets. הוא אינו קורס אוניברסיטאי, אינו מעניק נקודות זכות אקדמיות, ואף מוסד לימודים אינו מעורב בו.

היקפו תואם קורסי תכנות של שנה ראשונה כמו MIT 6.100L (לשעבר 6.0001), CS50 של Harvard, CS106A של Stanford ו-CS 1371 של Georgia Tech למהנדסים. אנו מקשרים לחומרים חינמיים לאורך כל הדרך. אף אחד מהארגונים האלה אינו תומך בדף זה.

מה אנחנו מוסיפים: כל דוגמה היא קוד פייתון אמיתי שסקריפט הבנייה שלנו מריץ לפני שהדף עולה, והפלט המודפס שלה חייב להתאים בדיוק למה שאתם רואים כאן. הנתונים מגיעים ממקורות ציבוריים אמיתיים: רשומת ה-CO₂ של מאונה לואה מ-NOAA, ניתוח הטמפרטורה GISTEMP של NASA ומדי נהרות של USGS.

אין צורך להתקין דבר: השתמשו ב-Google Colab או ב-JupyterLite, שמריץ פייתון בתוך הדפדפן בעזרת Pyodide. ההתקדמות שלכם נשמרת רק בדפדפן הזה.

איך הקורס הזה עוזר להציל את כדור הארץ

מדעי האקלים והסביבה פועלים על קוד. עקומת ה-CO₂, רשומות הטמפרטורה העולמית ותחזיות הנהרות כולן נבנות על ידי תוכניות שקוראות נתונים ציבוריים, ואתם יכולים לקרוא את אותם קבצים.

כל יחידה מסתיימת בחלק קצר עם מקורות שמראה איך הרעיונות שלה עוזרים לאנשים ולכדור הארץ.

צעדים ראשונים: משתנים, טיפוסים וביטויים

הריצו את קוד הפייתון הראשון שלכם במחברת בדפדפן, אחסנו ערכים במשתנים, וחשבו עם מספרים וטקסט.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לפתוח מחברת Colab או JupyterLite ולהריץ תאים.
  • להשתמש במשתנים ובטיפוסים int, float, str ו-bool.
  • להשתמש באופרטורים אריתמטיים, כולל //, % ו-**.
  • לעצב פלט בעזרת f-strings.

מושגי מפתח

  • תוכנית היא רצף של הוראות. מחברת מאפשרת להריץ אותן תא אחר תא ולראות תוצאות מיד.
  • משתנה הוא שם הקשור לערך: mass_kg = 1100. בחרו שמות שאומרים מה ובאילו יחידות.
  • לכל ערך יש טיפוס. int (מספרים שלמים), float (עשרוניים), str (טקסט) ו-bool (True/False) הם הבסיס; type() אומר לכם איזה.
  • / תמיד נותן float; // היא חלוקה שלמה; % הוא השארית; ** הוא חזקה.
  • ערכי float הם קירובים בינאריים: 0.1 + 0.2 אינו בדיוק 0.3, לכן השוו ערכי float עם סבולת.

בקרת זרימה: תנאים ולולאות

לגרום לתוכניות להחליט עם if/elif/else ולחזור על פעולות עם לולאות for ו-while.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • לכתוב if/elif/else עם אופרטורי השוואה ואופרטורים בוליאניים.
  • לעבור על טווחים ורצפים עם for.
  • להשתמש בלולאות while עם תנאי עצירה ברור.
  • לצבור סכומים וספירות.

מושגי מפתח

  • ההזחה מגדירה בלוקים בפייתון. ארבעה רווחים לכל רמה הם התקן.
  • השוואות (<, >=, ==, !=) מפיקות ערכים בוליאניים; שלבו אותן עם and, or, not.
  • for x in sequence חוזרת פעם אחת לכל איבר; range(a, b) נותן a, a+1, …, b−1.
  • while חוזרת עד שהתנאי שלה הוא False. ודאו שמשהו בתוך הלולאה משנה אותו, אחרת היא לא תסתיים לעולם.
  • תבנית הצובר: מתחילים סכום ב-0 ומוסיפים בתוך הלולאה.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

anomaly = 1.28   # NASA GISTEMP, 2024, deg C vs 1951-1980
if anomaly >= 1.0:
    print("at least 1.0 C above the 1951-1980 average")
elif anomaly > 0:
    print("warmer than average")
else:
    print("at or below average")
הצג את השלבים
  1. 1.28 ≥ 1.0, לכן הענף הראשון רץ והשאר מדולגים.

פלט

at least 1.0 C above the 1951-1980 average

תשובה: הענפים נבדקים לפי הסדר; רק הראשון שמתקיים רץ.

דוגמה 2.2 חברו את המספרים 1 עד 100 בלולאה.

total = 0
for n in range(1, 101):
    total += n
print(total)
הצג את השלבים
  1. range(1, 101) עוצר לפני 101.
  2. total += n מוסיף כל מספר.

פלט

5050

תשובה: 5050, בהתאמה לנוסחה של גאוס.

דוגמה 2.3 אם ה-CO₂ ימשיך לעלות ב-2.5 ppm בשנה מהממוצע של 2025, מתי הוא יעבור 450 ppm?

ppm = 427.35   # 2025 annual mean, Mauna Loa
year = 2025
while ppm < 450:
    ppm += 2.5
    year += 1
print(year, round(ppm, 2))
הצג את השלבים
  1. הלולאה מוסיפה 2.5 ppm ושנה אחת עד ש-ppm ≥ 450.

פלט

    הצג תשובה

  • אלגוריתם הוא שיטה מדויקת צעד אחר צעד. העלות שלו היא איך מספר הצעדים גדל עם גודל הקלט n.

  • לולאות מקוננות על n איברים הן O(n²): בסדר ל-1000 איברים, חסר סיכוי למיליון.
  • חיפושים במילון ובקבוצה הם O(1) בממוצע, וחיפושים ברשימה O(n).

def linear_search(xs, target):
    for i, x in enumerate(xs):
        if x == target:
            return i
    return -1

def binary_search(xs, target):
    lo, hi, steps = 0, len(xs) - 1, 0
    while lo <= hi:
        steps += 1
        mid = (lo + hi) // 2
        if xs[mid] == target:
            return mid, steps
        if xs[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1, steps

def bisect_root(f, a, b, tol=1e-6):
    n = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
        n += 1
    return (a + b) / 2, n

import math
GM = 3.986e14
r0 = 6.771e6
x, y = r0, 0.0
vx, vy = 0.0, math.sqrt(GM / r0)
dt, t = 1.0, 0
period = 2 * math.pi * math.sqrt(r0**3 / GM)
while t < period:
    r3 = (x * x + y * y) ** 1.5
    vx -= GM * x / r3 * dt          # Euler-Cromer: update velocity first
    vy -= GM * y / r3 * dt
    x += vx * dt
    y += vy * dt
    t += dt
print(round(period / 60, 1), "min;", round(math.hypot(x, y) / 1000), "km from Earth's center")

import math
def fly(v0, deg, k=0.0, dt=0.001, g=9.81):
    vx, vy = v0 * math.cos(math.radians(deg)), v0 * math.sin(math.radians(deg))
    x = y = 0.0
    while y >= 0:
        v = math.hypot(vx, vy)
        vx -= k * v * vx * dt
        vy -= (g + k * v * vy) * dt
        x += vx * dt
        y += vy * dt
    return x
for k in (0.0, 0.01, 0.05):
    best = max(range(20, 61), key=lambda a: fly(20, a, k))
    print(k, best, round(fly(20, best, k), 1))
