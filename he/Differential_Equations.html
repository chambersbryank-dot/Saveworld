על הקורס

זהו מתווה של קורס חינמי ללימוד עצמי שנכתב על ידי Saving Planets. הוא אינו קורס אוניברסיטאי, אינו מעניק נקודות זכות אקדמיות, ואף מוסד לימודים אינו מעורב בו.

ההיקף תואם קורס שנה ב׳ במשוואות דיפרנציאליות רגילות, בהשראת הנושאים והעומק של MIT OpenCourseWare 18.03 ושל ספרי הלימוד החינמיים של Jiří Lebl ‏(Notes on Diffy Qs) ו-William Trench, ושל סילבוסים של קורסים כמו Georgia Tech MATH 2552 ו-Stanford Math 53. אנו מקשרים לחומרים החינמיים לאורך כל הקורס. אף אחד מהמחברים או מהארגונים האלה אינו תומך בדף זה.

מה אנחנו מוסיפים: כל יחידה מתחברת לבעיה אמיתית של כדור הארץ עם מקור ציבורי מצוטט (אגמים, מתאן, דיג, פחמן, אקלים, מגפות, טורבינות רוח), כל מספר בדף מחושב מחדש בסקריפט בדיקה לפני פרסומו, וארבע מעבדות מחשב פותרות מודלים אמיתיים באופן נומרי.

עברו עליו לפי הסדר. בכל יחידה יש מטרות, רעיונות מרכזיים, משוואות, דוגמאות צעד אחר צעד, תרגול עם תשובות מלאות, טעויות נפוצות, כרטיסיות ובוחן. ההתקדמות שלכם נשמרת רק בדפדפן הזה.

איך הקורס הזה עוזר להציל את כדור הארץ

כמעט כל מודל של כדור הארץ החי הוא משוואה דיפרנציאלית: כמה מהר אגם שוטף מזהם, איך מלאי דגים מתאושש, איך פחמן נע בין האוויר לים, כמה מהר כדור הארץ מתחמם כשמאזן האנרגיה שלו משתנה, איך מגפה מתפשטת, ואיך מגדל של טורבינת רוח מתנדנד.

כל יחידה מסתיימת בקטע קצר עם מקורות שמראה איך הרעיונות שלה עוזרים גם לאנשים וגם לטבע. פרמטרים של מודלים שאינם ממקור מסומנים כערכי דוגמה.

יחידה 1 · שבועות 1–2

משוואות מסדר ראשון

שדות כיוונים, משוואות פרידות, משוואות לינאריות עם גורם אינטגרציה, משוואות מדויקות, ומתי פתרון קיים ויחיד.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • קראו שדה כיוונים ושרטטו פתרונות.
  • פתרו משוואות פרידות ולינאריות מסדר ראשון.
  • זהו ופתרו משוואות מדויקות.
  • נסחו את משפט הקיום והיחידות וזהו מתי הוא נכשל.

מושגי מפתח

  • משוואה דיפרנציאלית מקשרת פונקציה לא ידועה לנגזרותיה; פתרון הוא פונקציה שמקיימת אותה.
  • פרידה: dy/dx = g(x)h(y). חלקו ובצעו אינטגרציה בשני האגפים.
  • לינארית: y′ + p(x)y = q(x). הכפילו בגורם האינטגרציה μ = e^(∫p dx) כך שהאגף השמאלי יהפוך ל-(μy)′.
  • מדויקת: M dx + N dy = 0 עם M_y = N_x היא dF = 0, ולכן F(x, y) = C.
  • אם f ו-∂f/∂y רציפות ליד (x₀, y₀), אז ל-y′ = f(x, y), y(x₀) = y₀ יש בדיוק פתרון אחד בסביבה. ובכל זאת פתרונות עלולים להתפוצץ בזמן סופי.

משוואות מפתח

דוגמאות פתורות שלב אחר שלב

דוגמה 1.1 פתרו dy/dx = xy, y(0) = 2, ומצאו את y(1).

הצג את השלבים
  1. dy/y = x dx, ולכן ln|y| = x²/2 + C.
  2. y = 2e^(x²/2).
  3. y(1) = 2e^0.5.

תשובה: ≈ 3.297.

דוגמה 1.2 פתרו y′ + 2y = 4, y(0) = 0, ומצאו את y(1).

הצג את השלבים
  1. μ = e^(2t), ולכן (e^(2t)y)′ = 4e^(2t).
  2. e^(2t)y = 2e^(2t) + C; y(0) = 0 נותן C = −2.
  3. y = 2(1 − e^(−2t)).

תשובה: y(1) ≈ 1.729, ומתקרב למצב היציב 2.

דוגמה 1.3 פתרו 2xy dx + (x² + 2y) dy = 0 עם y(0) = 1, ומצאו את y כאשר x = 1.

הצג את השלבים
  1. M_y = 2x = N_x: מדויקת.
  2. F = x²y + y²; F(0, 1) = 1.
  3. ב-x = 1: y + y² = 1, ולכן y = (−1 + √5)/2.

תשובה: ≈ 0.618.

תרגילים

פתרו כל אחד קודם על נייר, ואז בדקו.

  1. פתרו y′ = y², y(0) = 1. היכן הפתרון קיים?

    הצג תשובה

    y = 1/(1 − t); הוא מתפוצץ ב-t = 1, אף ש-y² חלקה בכל מקום.

  2. פתרו t y′ + y = t² עבור t > 0.

    הצג תשובה

    (ty)′ = t², ולכן y = t²/3 + C/t.

  3. פתרו y′ = −y/τ.

    הצג תשובה

    y = y₀e^(−t/τ).

  4. האם (y cos x) dx + (sin x + 2y) dy = 0 מדויקת? פתרו.

    הצג תשובה

    M_y = cos x = N_x; F = y sin x + y² = C.

  5. האם ל-y′ = √y, y(0) = 0 יש פתרון יחיד?

    הצג תשובה

    לא: y = 0 ו-y = t²/4 שניהם מתאימים; ∂f/∂y = 1/(2√y) אינה רציפה ב-y = 0.

תפיסות שגויות נפוצות

  • מיתוס: כל משוואה מסדר ראשון היא פרידה.

    בפועל: y′ = x + y אינה; היא לינארית.

  • מיתוס: אפשר לשכוח את +C עד הסוף.

    בפועל: הוסיפו C כשמבצעים אינטגרציה, לפני שמבודדים את y, אחרת תנאי ההתחלה ייצא שגוי.

  • מיתוס: אגף ימין חלק פירושו שהפתרון חי לנצח.

    בפועל: y′ = y² מתפוצצת בזמן סופי.

כרטיסיות

  • פרידה

    dy/dx = g(x)h(y).

  • לינארית מסדר ראשון

    y′ + p y = q.

  • גורם אינטגרציה

    μ = e^(∫p dx).

  • מדויקת

    M_y = N_x; F = C.

  • בעיית התחלה

    מד״ר ועוד y(x₀) = y₀.

  • קיום ויחידות

    f, f_y רציפות ⇒ פתרון מקומי אחד.

בוחן לבדיקה עצמית

1. גורם האינטגרציה של y′ + 3y = x הוא…

הצג תשובה

e^(3x). e^(∫3 dx).

e^(∫3 dx).

2. M dx + N dy = 0 מדויקת כאשר…

הצג תשובה

M_y = N_x. הנגזרות המעורבות של F שוות.

הנגזרות המעורבות של F שוות.

3. ל-y′ = ky יש פתרון…

הצג תשובה

y₀e^(kt). פרידה.

פרידה.

4. היחידות עלולה להיכשל כאשר…

הצג תשובה

∂f/∂y אינה רציפה. למשל y′ = √y ב-0.

למשל y′ = √y ב-0.

איך זה עוזר להציל את כדור הארץ

המשוואה הפשוטה ביותר מסדר ראשון, y′ = −y/τ, מתארת איך מזהם מתפנה מאגם מעורבב היטב או איך גז עוזב את האטמוספרה. המספר היחיד שלה, סקאלת הזמן τ, קובע אם טעות תדעך בתוך שנים או תימשך מאות שנים (יחידה 2).

מושגי מפתח

  • קצב שינוי = קצב כניסה − קצב יציאה. כתבו את היחידות של כל איבר.
  • אגם מעורבב היטב עם זמן שהייה τ מאבד מזהם בקצב C/τ ברגע שהזרימה הנכנסת נקייה.
  • במשוואה אוטונומית y′ = f(y), נקודות שיווי המשקל פותרות f(y) = 0; שיווי משקל יציב אם f′(y) < 0.
  • גדילה לוגיסטית P′ = rP(1 − P/K) מתייצבת ב-K. עם קציר קבוע H, הקציר בר הקיימא הגדול ביותר הוא rK/4, ב-P = K/2.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • פתרו ay″ + by′ + cy = 0 בעזרת המשוואה האופיינית.
  • טפלו בשורשים ממשיים, כפולים ומרוכבים.
  • מדלו מערכות מסה-קפיץ-מרסן.
  • סווגו את הריסון וחשבו את התדירות הטבעית ואת הריסון הקריטי.

מושגי מפתח

  • נסו y = e^(rt): ar² + br + c = 0. שני שורשים ממשיים נותנים שתי פונקציות מעריכיות; שורש כפול נותן (c₁ + c₂t)e^(rt); שורשים מרוכבים α ± iβ נותנים e^(αt)(c₁ cos βt + c₂ sin βt).

  • ריסון c < 2√(mk) מתנודד ודועך (תת-ריסון); c = 2√(mk) חוזר הכי מהר בלי לחרוג (קריטי).

תנודות מאולצות ותהודה

משוואות לא הומוגניות, מקדמים לא ידועים, תגובת המשרעת של מתנד מאולץ, פעימות ותהודה.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • מצאו פתרונות פרטיים בשיטת המקדמים הלא ידועים.
  • כתבו את הפתרון הכללי כפתרון הומוגני ועוד פתרון פרטי.
  • חשבו את משרעת המצב היציב של מתנד מרוסן מאולץ.
  • הסבירו תהודה ואיך מהנדסים נמנעים ממנה.

מושגי מפתח

  • פתרון כללי = פתרון הומוגני + פתרון פרטי אחד.
  • נחשו את הצורה לפי הכוח המאלץ: עבור cos ωt נסו A cos ωt + B sin ωt.
  • כשהוא מאולץ בתדירות ω, מתנד מרוסן מתייצב בתנועה קבועה עם משרעת X = F₀/√((k − mω²)² + (cω)²).

מטרות הלמידה

  • פתרו x′ = Ax בעזרת ערכים עצמיים ווקטורים עצמיים.
  • שרטטו דיוקנאות פאזה.
  • סווגו את הראשית בעזרת העקבה והדטרמיננטה.

מושגי מפתח

מערכות לא לינאריות ויציבות

נקודות שיווי משקל של מערכות לא לינאריות, לינאריזציה עם היעקוביאן, מחזורי טורף-נטרף ומודל המגפה SIR.

מטרות הלמידה

בסוף היחידה הזו תוכלו:

  • מצאו נקודות שיווי משקל של מערכות לא לינאריות.
  • בצעו לינאריזציה עם היעקוביאן וסווגו נקודות שיווי משקל.
  • נתחו את מודל טורף-נטרף של לוטקה–וולטרה.
  • השתמשו במודל SIR: ‏R₀, סף חסינות העדר והגודל הסופי.

מושגי מפתח

  • ליד נקודת שיווי משקל, מערכת לא לינארית מתנהגת כמו הלינאריזציה שלה x′ = J x, כאשר J הוא היעקוביאן (אלא אם הלינאריזציה היא מרכז).
  • לוטקה–וולטרה: נטרפים x′ = ax − bxy, טורפים y′ = −cy + dxy. נקודת שיווי המשקל היא (c/d, a/b); האוכלוסיות נעות סביבה במחזוריות.
  • SIR: S′ = −βSI, I′ = βSI − γI, R′ = γI. מספר ההדבקה הבסיסי R₀ = β/γ; התפרצות גדלה רק אם R₀S > 1.
  • סף חסינות העדר הוא 1 − 1/R₀; החלק הסופי שלא נדבק s∞ פותר ln s∞ = R₀(s∞ − 1).
