Project Seagrass

Project Seagrass, ארגון צדקה בריטי, שתל יותר מ-150,000 זרעי עשב ים כדי להחזיר כרי מרעה תת-ימיים (נתוני הארגון).

תמונה: NASA/KSC ‏(KSC-20230329-PH-KLS01_0304, פרויקט שיקום עשב ים).

חמשת ה-W של Project Seagrass

מי

Project Seagrass, ארגון צדקה רשום באנגליה ובוויילס (1162824) ובסקוטלנד (SC046788).

מקור: Project Seagrass

מה

הגנה על כרי עשב ים ושיקומם באמצעות עבודה קהילתית, מחקר ונטיעה.

מקור: Project Seagrass

מתי

פועלת מאז 2013; היא מדווחת על יותר מ-150,000 זרעים שנשתלו ויותר מ-3,000 נקודות נתונים חדשות על עשב ים.

מקור: Project Seagrass

איפה

פועלת מברידג'נד, ויילס, בריטניה, מחופים מקומיים ועד מדיניות בינלאומית.

מקור: Project Seagrass

למה

כרי עשב ים רבים משתנים בכ-1–2% בכל שנה, והפסדים קטנים מצטברים לירידות גדולות.

מקור: Project Seagrass
