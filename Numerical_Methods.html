About this course

This is a free self-study course outline written by Saving Planets. It is not a university course, it carries no academic credit, and no school is involved.

Its scope follows a one-semester junior numerical methods course for engineers. It is modeled on the topics and depth of MIT 18.330 Introduction to Numerical Analysis, MIT 2.086 Numerical Computation for Mechanical Engineers and MIT 10.34 (free on MIT OpenCourseWare), using free OpenStax calculus sections, which we link where they help. None of those authors, schools or agencies endorses this page.

What we add: every unit ties to real work with a cited public source (NOAA’s Global Forecast System and supercomputers, the Mauna Loa CO₂ record, USGS groundwater models and NASA climate models), every number on the page is re-computed by a checking script before it goes live, and every lab has a free simulation or a spreadsheet.

Work through it in order. Each unit has goals, key ideas, equations, step-by-step examples, practice with full answers, common mistakes, flashcards and a quiz. Your progress is saved only in this browser.

How this course helps save the planet

Weather forecasts, climate projections and groundwater plans are all numerical methods running on computers: the equations cannot be solved by hand, so they are broken into grids, time steps and huge linear systems.

Knowing how those methods work, and how they fail, is how engineers judge a forecast or a model. Each unit ends with a short, sourced section. Values that are not from a source are labeled as sample or textbook values.

Before you start

Prerequisites

  • Calculus I and II: derivatives, integrals and Taylor series.
  • Differential Equations: first-order and second-order ODEs.
  • Linear Algebra: matrices, determinants and eigenvalues.
  • Intro Programming: loops, functions and arrays (a spreadsheet also works).

How to study

  • Before computing, estimate the answer and decide what accuracy you need.
  • Always compare against an exact answer on a test problem before trusting a method on a real one.
  • Track the error as you halve the step: the ratio tells you the order of the method.
  • Keep units in SI and write the step size with its units.
  • Watch for subtracting nearly equal numbers; rewrite the formula if you can.
  • Do every practice problem on paper or in a spreadsheet before opening the answer, and retake the quizzes a few days later.

Lab equipment (for the wet labs)

  • A computer or tablet for the free PhET Least-Squares Regression, Curve Fitting, Calculus Grapher and Projectile Motion simulations.
  • Spreadsheet software (any free one works), or Python if you know it.
  • NOAA’s Mauna Loa CO₂ data file in a web browser.
  • A calculator.

Unit 1 · Week 1

Errors, Floating-Point Numbers and Taylor Series

Absolute and relative error, significant digits, IEEE 754 floating-point numbers, machine epsilon, rounding and cancellation, and truncation error from Taylor series.

Learning objectives

By the end of this unit you can:

  • Compute absolute and relative error.
  • Explain machine epsilon for single and double precision.
  • Spot and fix catastrophic cancellation.
  • Bound truncation error with the next Taylor term.

Key concepts

  • Absolute error is |approximate − exact|; relative error divides by |exact|. Relative error tells you how many digits are right.
  • Computers store numbers in binary floating point. Double precision has machine epsilon 2⁻⁵² ≈ 2.22 × 10⁻¹⁶ (about 16 digits); single precision has 2⁻²³ ≈ 1.19 × 10⁻⁷ (about 7 digits).
  • Most decimals, like 0.1, have no exact binary form, so 0.1 + 0.2 − 0.3 comes out as about 5.55 × 10⁻¹⁷ instead of 0.
  • Subtracting nearly equal numbers loses digits (catastrophic cancellation). Rewriting the formula algebraically often fixes it.
  • Truncation error comes from cutting off an infinite process, such as a Taylor series. The first dropped term estimates the error.

Key equations

Worked examples, step by step

Example 1.1 Find the relative error of 22/7 as an approximation to π.

Show the steps
  1. |22/7 − π| = 0.001264.
  2. Divide by π.

Answer: Relative error = 4.02 × 10⁻⁴, so about 3 correct digits.

Example 1.2 Compute √(10⁸ + 1) − √(10⁸) safely.

Show the steps
  1. Direct subtraction cancels most digits.
  2. Use 1/(√(10⁸ + 1) + √(10⁸)).

Answer: 5.0 × 10⁻⁵ (more exactly 4.99999999875 × 10⁻⁵).

Example 1.3 Estimate the error of e^0.1 ≈ 1 + 0.1.

Show the steps
  1. The next term is 0.1²/2 = 0.005.
  2. The true error is e^0.1 − 1.1.

Answer: Error = 0.00517, close to the 0.005 estimate.

Practice problems

Work each on paper first, then check.

  1. How many correct digits does double precision give?

    Show answer

  2. Add the 0.1³/6 term to e^0.1 ≈ 1.1. New error?

    Show answer

    1.71 × 10⁻⁴.

  3. Why is 0.1 + 0.2 − 0.3 not exactly 0 on a computer?

    Show answer

    0.1 and 0.2 have no exact binary form; the result is about 5.55 × 10⁻¹⁷.

  4. What is single-precision epsilon?

    Show answer

    2⁻²³ = 1.19 × 10⁻⁷.

Common misconceptions

  • Myth: Computers do exact arithmetic.

    Actually: Every operation rounds to the nearest floating-point number.

  • Myth: Smaller steps always mean smaller error.

    Actually: Rounding error grows as steps shrink.

  • Myth: Relative and absolute error are the same.

    Actually: Relative error divides by the true size.

Flashcards

    |approx − exact|.

  • Relative error

    Absolute error / |exact|.

  • Machine epsilon

    2⁻⁵² ≈ 2.22 × 10⁻¹⁶ in double.

  • Cancellation

    Digit loss when subtracting close numbers.

  • Truncation error

    From cutting off an infinite process.

  • Single precision

    About 7 digits.

How this helps save the planet

NOAA’s Environmental Modeling Center describes a coupled global forecast run at about 3 km resolution that ran its atmospheric dynamics in 32-bit precision and everything else in 64-bit precision, a deliberate trade between speed and accuracy.

Unit 2 · Weeks 2–3

Roots of Equations: Bisection, Newton and Secant

Bracketing with bisection, Newton’s method, the secant method, fixed-point iteration, convergence order and stopping rules.

Learning objectives

By the end of this unit you can:

  • Find a root by bisection and predict the number of steps.
  • Apply Newton’s method and recognize quadratic convergence.
  • Use the secant method when the derivative is unknown.
  • Choose a stopping rule.

Key concepts

  • Bisection halves a bracket [a, b] where f changes sign. It always converges, but only one binary digit per step: n ≥ log₂((b − a)/tol).
  • Newton’s method follows the tangent line: x_{n+1} = x_n − f(x_n)/f′(x_n). Near a simple root it converges quadratically, doubling the correct digits each step.
  • The secant method replaces f′ with the slope through the last two points. It needs no derivative and converges with order about 1.618.
  • Newton can fail if f′ is near zero or the start is far away; a bracketing fallback makes it safe.
  • Stop when |x_{n+1} − x_n| and |f(x_n)| are both below tolerance, and always cap the number of iterations.

Key equations

Worked examples, step by step

Example 2.1 Use bisection on f(x) = x³ − x − 2 on [1, 2]. Give the first three midpoints and the root.

Show the steps
  1. f(1) = −2, f(2) = 4.
  2. Midpoints 1.5, 1.75, 1.625.

Answer: Root x = 1.5214.

Example 2.2 How many bisection steps shrink a width-1 bracket below 10⁻⁶?

Show the steps
  1. log₂(10⁶) = 19.93.

Answer: 20 steps.

Example 2.3 Use Newton’s method on x² − 2 from x₀ = 1.

Show the steps
  1. x₁ = 1.5, x₂ = 1.41667.
  2. x₃ = 1.414216.

Answer: x₃ = 1.414216, already 6 correct digits.

Practice problems

Work each on paper first, then check.

    Show answer

  2. Apply the secant method to x² − 2 from 1 and 2. First three iterates?

    Show answer

  3. What convergence order does the secant method have?

    Show answer

    About 1.618.

  4. Why cap the iteration count?

    Show answer

    A method may diverge or cycle.

Common misconceptions

  • Myth: Newton always converges.

    Actually: It can diverge from a poor start.

  • Myth: Bisection is fast.

    Actually: It gains one bit per step.

  • Myth: A small f(x) means x is close to the root.

    Actually: Not if f is very flat.

Unit 3 · Week 4

Linear Systems: Gaussian Elimination, LU and Conditioning

Gaussian elimination with partial pivoting, LU factorization, operation counts, the condition number and how it limits accuracy.

Learning objectives

By the end of this unit you can:

  • Solve a 3 × 3 system by elimination.
  • Explain LU factorization and reuse.
  • Estimate the cost of elimination.
  • Use the condition number to judge accuracy.

Key concepts

  • Gaussian elimination reduces Ax = b to an upper-triangular system, then back-substitutes. Partial pivoting swaps rows so the largest pivot is used, which controls rounding error.
  • LU factorization stores the elimination as A = LU. Once factored, each new right-hand side costs only two triangular solves.
  • Elimination costs about 2n³/3 floating-point operations: doubling n multiplies the work by 8.
  • The condition number κ(A) = ‖A‖‖A⁻¹‖ measures sensitivity. You can lose about log₁₀ κ digits of accuracy.
  • Never compute A⁻¹ to solve a system; factor and solve instead.

Key equations

Worked examples, step by step

Example 3.1 Solve 2x + y − z = 8, −3x − y + 2z = −11, −2x + y + 2z = −3.

Show the steps
  1. Eliminate x from rows 2 and 3, then y from row 3.
  2. Back-substitute.

Answer: x = 2, y = 3, z = −1.

Example 3.2 Estimate the elimination cost for n = 1000.

Show the steps
  1. 2 × 1000³/3.

Answer: About 6.67 × 10⁸ flops.

Example 3.3 Find the 2-norm condition number of [[1, 1], [1, 1.0001]].

Show the steps
  1. The rows are nearly parallel.
  2. κ = σ_max/σ_min.

Answer: κ ≈ 40,002, so about 4–5 digits can be lost.

Practice problems

Work each on paper first, then check.

  1. How much more work is n = 2000 than n = 1000?

    Show answer

    8 times.

  2. Elimination flops for n = 3?

    Show answer

    2 × 27/3 = 18.

  3. Why pivot?

    Show answer

    To avoid dividing by small numbers and amplifying rounding.

  4. Digits lost with κ = 10⁸ in double precision?

    Show answer

    About 8 of 16.

Common misconceptions

  • Myth: Use A⁻¹ to solve systems.

    Actually: Factor and solve; it is cheaper and more accurate.

  • Myth: A small determinant means ill-conditioned.

    Actually: Use the condition number.

  • Myth: Pivoting is optional.

    Actually: Without it, elimination can fail or lose accuracy.

    Row swaps for stability.

  • Condition number

    ‖A‖‖A⁻¹‖.

  • Back substitution

    Solve triangular systems.

  • Cost

    ≈ 2n³/3.

Unit 4 · Week 5

Iterative Solvers: Jacobi, Gauss–Seidel and Convergence

Jacobi and Gauss–Seidel iteration, diagonal dominance, the iteration matrix and spectral radius, sparse systems and why iterative methods scale.

Learning objectives

By the end of this unit you can:

  • Carry out Jacobi and Gauss–Seidel steps.
  • Test diagonal dominance.
  • Use the spectral radius to predict convergence speed.
  • Explain why large sparse systems use iteration.

Key concepts

  • Jacobi updates every unknown from the previous iterate; Gauss–Seidel uses new values as soon as they are computed.
  • If A is strictly diagonally dominant, both methods converge from any start.
  • The error shrinks each step by about the spectral radius ρ of the iteration matrix. Gauss–Seidel often has ρ_GS = ρ_J².
  • Large grids give sparse matrices with only a few nonzeros per row. Iterative methods store only those nonzeros, while elimination fills in.
  • Stop when the residual ‖b − Ax‖ is small relative to ‖b‖.

Key equations

Worked examples, step by step

Example 4.1 Do two Jacobi steps on 4x + y = 1, x + 3y = 2 from (0, 0).

Show the steps
  1. Step 1: x = 1/4 = 0.25, y = 2/3 = 0.6667.
  2. Step 2: x = (1 − 0.6667)/4, y = (2 − 0.25)/3.

Answer: x = 0.0833, y = 0.5833 (exact 0.0909, 0.6364).

Example 4.2 Do two Gauss–Seidel steps on the same system.

Show the steps
  1. Step 1: x = 0.25, y = (2 − 0.25)/3 = 0.5833.
  2. Step 2: x = 0.1042, y = 0.6319.

Answer: x = 0.1042, y = 0.6319, closer than Jacobi.

Example 4.3 Find the Jacobi and Gauss–Seidel spectral radii for that system.

Show the steps
  1. ρ_J = √(1/12).
  2. ρ_GS = ρ_J² = 1/12.

Answer: ρ_J = 0.289; ρ_GS = 0.0833.

Practice problems

Work each on paper first, then check.

  1. Is [[4, 1], [1, 3]] diagonally dominant?

    Show answer

    Yes: 4 > 1 and 3 > 1.

  2. Steps for Gauss–Seidel (ρ = 0.0833) to cut error by 10⁶?

    Show answer

    About 6 (0.0833⁶ = 3.35 × 10⁻⁷).

  3. Third Gauss–Seidel iterate?

    Show answer

    x = 0.0920, y = 0.6360.

  4. Why not eliminate on a million-unknown grid?

    Show answer

    Fill-in uses too much memory and time.

Common misconceptions

  • Myth: Iteration always converges.

    Actually: It needs ρ < 1.

  • Myth: Jacobi and Gauss–Seidel are the same.

    Actually: Gauss–Seidel uses new values immediately.

  • Myth: A small change between steps means converged.

    Actually: Check the residual too.

Flashcards

    Update all from old values.

  • Gauss–Seidel

    Use new values immediately.

  • Spectral radius

    Largest |eigenvalue|.

  • Diagonal dominance

    |a_ii| > row sum.

  • Sparse

    Mostly zeros.

  • Residual

    b − Ax.

How this helps save the planet

NOAA’s GFS divides the atmosphere into 127 vertical layers at about 13 km horizontal spacing. Each grid point couples only to its neighbours, so the systems such models build are huge and sparse.

With a textbook Earth surface area of 5.1 × 10⁸ km², a 13 km grid has about 3.0 million columns and 383 million cells. Systems that size are handled with iterative and other sparse methods, not plain elimination.

Unit 5 · Weeks 6–7

Interpolation, Splines and Least-Squares Fitting

Linear and polynomial interpolation, Lagrange form, the danger of high-degree polynomials, cubic splines, and least-squares line and polynomial fits with residuals.

Learning objectives

By the end of this unit you can:

  • Interpolate linearly between data points.
  • Build a Lagrange polynomial.
  • Fit a least-squares line and interpret its slope.
  • Choose between interpolation and fitting.

Key concepts

  • Interpolation passes exactly through the data; fitting passes near noisy data and minimizes the sum of squared residuals.
  • A degree-n polynomial through n + 1 points is unique. High degrees on equally spaced points can oscillate wildly near the ends (Runge’s phenomenon).
  • Cubic splines join cubic pieces with matching slope and curvature, giving smooth curves without wild swings.
  • The least-squares line solves the normal equations AᵀAc = Aᵀy. The slope is a rate, with units.
  • Plot the residuals: a pattern in them means the model is missing something, such as curvature.

Key equations

Worked examples, step by step

Example 5.1 NOAA’s Mauna Loa annual means are 390.10 ppm (2010) and 414.21 ppm (2020). Interpolate 2015.

Show the steps
  1. y = 390.10 + 0.5 × 24.11.

Answer: 402.16 ppm; NOAA’s 2015 value is 401.01, so the record curves upward.

Example 5.2 Fit a least-squares line to the decade values 1960–2020 (316.91, 325.68, 338.76, 354.45, 369.71, 390.10, 414.21 ppm).

Show the steps
  1. Solve the normal equations for slope and intercept.

Answer: Slope 1.613 ppm per year; the line predicts 415.0 ppm for 2025.

Example 5.3 Fit a quadratic in t = year − 1960 instead.

Show the steps
  1. Least squares with columns 1, t, t².

Answer: c = 316.84 + 0.810t + 0.01338t²; it predicts 426.0 ppm for 2025, close to NOAA’s 427.35.

  4. Interpolate or fit noisy lab data?

    Actually: They can oscillate between points.

  • Myth: A good R² means a good model.

    Actually: Check the residual pattern.

  • Myth: Extrapolation is as safe as interpolation.

    Actually: It is much riskier.

Unit 6 · Week 8

Numerical Differentiation

Forward, backward and central differences, their truncation error, the balance with rounding error and the best step size, second derivatives, and Richardson extrapolation.

Learning objectives

By the end of this unit you can:

  • Apply forward and central differences.
  • State the order of each formula.
  • Choose a step size that balances truncation and rounding.
  • Estimate a second derivative.

Key concepts

  • The forward difference (f(x + h) − f(x))/h has error proportional to h (first order).
  • The central difference (f(x + h) − f(x − h))/(2h) has error proportional to h² (second order), so halving h cuts the error by 4.
  • Rounding error grows like ε/h as h shrinks. For forward differences the best h is about √ε ≈ 1.49 × 10⁻⁸; for central differences about ε^(1/3) ≈ 6.06 × 10⁻⁶.
  • The second derivative is (f(x + h) − 2f(x) + f(x − h))/h², also second order.
  • Richardson extrapolation combines two step sizes to cancel the leading error term.

Key equations

Learning objectives

By the end of this unit you can:

  • Use Romberg to improve a result.
  • Apply 2-point Gaussian quadrature.

Key concepts

  • The trapezoidal rule joins points with straight lines. Its error falls like h²: doubling n cuts it by 4.

Ordinary Differential Equations: Euler, Runge–Kutta and Stability

Euler’s method, Heun’s method, fourth-order Runge–Kutta, local and global error, stability limits, stiff equations and implicit methods, and systems of ODEs.

Learning objectives

By the end of this unit you can:

  • Step an ODE with Euler and RK4.
  • Relate step size to global error.
  • Find the explicit stability limit for y′ = −λy.
  • Recognize stiff problems.

Key concepts

  • Euler’s method y_{n+1} = y_n + h f(t_n, y_n) has global error proportional to h (first order).
  • Fourth-order Runge–Kutta (RK4) uses four slope samples per step; its global error falls like h⁴.
  • For y′ = −λy, explicit Euler is stable only if h < 2/λ. Outside that, the numerical solution grows even though the true one decays.

  • Higher-order ODEs become first-order systems, which the same methods solve.

Partial Differential Equations: Finite Differences

Grids and stencils, the explicit heat equation and its stability limit, implicit and Crank–Nicolson schemes, Laplace’s equation and iterative solution, the CFL condition for waves, and the cost of resolution.

Learning objectives

By the end of this unit you can:

  • Write finite-difference stencils for the heat and Laplace equations.
  • Apply the explicit stability limit r ≤ ½.
  • Explain the CFL condition.
  • Estimate how cost grows with resolution.

Key concepts

  • Replace derivatives with differences on a grid. For u_t = αu_xx, the explicit scheme is u_i^{n+1} = u_i^n + r(u_{i+1}^n − 2u_i^n + u_{i−1}^n) with r = αΔt/Δx².

Glossary

Absolute error
Size of the difference from the true value.
Bisection
Root finding by halving a sign-change bracket.
CFL condition
Time-step limit cΔt/Δx ≤ 1.
Catastrophic cancellation
Digit loss when subtracting close numbers.
Condition number
How much a problem amplifies input errors.
Crank–Nicolson
Implicit second-order time scheme.
Diagonal dominance
Each diagonal entry outweighs the rest of its row.
Gaussian quadrature
Integration with optimal points and weights.
Gauss–Seidel
Iterative solver using new values at once.
LU factorization
A = LU, reusable elimination.
Least squares
Fit minimizing the sum of squared residuals.
Machine epsilon
Gap between 1 and the next float.
Newton’s method
Root finding along tangent lines.
Power method
Repeated multiplication to find the dominant eigenvalue.
Runge–Kutta (RK4)
Fourth-order ODE solver.
Simpson’s rule
Fourth-order integration with parabolas.
Spline
Smooth piecewise cubic curve.
Stiff equation
ODE with very fast and very slow parts.
Truncation error
Error from cutting off an infinite process.
Validation
Checking a model against observations.
